# 数字教材整书预览版 overall-0.5 clean preview

生成日期：2026-06-27  
入口：`index.html`

## 定位

本目录用于观察“最终数字教材呈现层”的阅读效果。它从 `overall-0.5` 复制生成，但隐藏或改写了会干扰观察的研发过程语言，例如“占位、候选、未接入、不是定稿、评审准备、发布门禁”等。

原 `samples/digital_textbook_overall_prototype_overall_0_5/` 仍作为治理评审版保留，用于查看过程资产、风险边界、旧版本入口、课程能力图谱关系评审和发布前门禁。

## 与治理版的区别

1. 首页默认按数字教材学习入口呈现，不再以原型/母版/候选样章作为主文案。
2. 项目一、三、五、六按整书课程项目呈现，不使用“结构占位”标签。
3. 项目二、项目四作为重点学习路径呈现，突出测试数据到优化验证的证据流转。
4. P4-T2作为可进入的学习任务页呈现，不再称为“深样章”。
5. 图谱页以分层关系图呈现课程主链、项目路径、能力节点、资源卡片和评价产出之间的挂接关系。
6. 一级导航只保留“课程、项目、图谱、教师”，避免把资源治理和交付说明误当成学生学习主路径。
7. 任务资源映射、素材子平台说明和交付说明统一放入“平台支持”辅助入口，用于说明支撑关系，不作为学习主界面。

## 保留内容

1. 整书6个项目、18个学习任务的目录结构。
2. 项目二和项目四的重点学习路径。
3. P4-T2两课时学习任务页。
4. 课程能力图谱在学习路径中的导航作用。
5. 教师“任务组织、讲评与复核”视图。
6. 平台支持辅助入口中的任务资源映射、素材子平台说明和交付说明。

## 专家反馈吸收状态

2026-06-29已根据专家反馈完成一轮呈现层调整：

1. 教师侧从“教师带教/资源准备”改为“AI预生成任务组织、讲评与复核建议，教师审核确认”。
2. 资源和交付从一级导航移出，改为平台支持辅助入口。
3. 图谱节点补充资源卡片、学习活动和评价产出的可追踪挂接。
4. P4-T2任务页将教师页签改为“任务组织”，保留任务内“任务资源”作为完成该任务所需学习材料入口。
5. 已通过 `qa/run_expert_feedback_absorption_qa.cjs`、`qa/run_navigation_qa.cjs`、`qa/run_graph_resource_qa.cjs` 页面级检查。

## 使用建议

对外或给非项目成员观察最终呈现时，优先打开本目录的 `index.html`。

`digital_textbook_overall_prototype/`、`digital_textbook_overall_prototype_phase2_p4_loop/`、`digital_textbook_overall_prototype_phase3_p2_loop/` 是从历史阶段复制过来的追溯材料，不属于当前正式预览体验入口。正式观察时不要直接打开这些子目录，以免把旧阶段导航结构误判为当前成果。

需要评审图谱关系、资源风险、媒体审查、接口边界和版本追溯时，仍打开原治理版：

`../digital_textbook_overall_prototype_overall_0_5/index.html`
