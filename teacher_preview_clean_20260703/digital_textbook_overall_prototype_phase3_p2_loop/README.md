# 阶段3项目二闭环复制验证原型

生成日期：2026-06-26  
版本：overall-0.4-phase3-p2  
入口：`index.html`

## 定位

本原型是在阶段2项目四闭环样本通过完成性复核后，复制验证到项目二的阶段3样本。它不覆盖阶段2原型，也不替代后续任务级深样章。

本版本只验证项目二三任务能否形成可教学、可导航、可审核的闭环：

```text
P2-T1 DT/CQT测试准备和执行
-> 正常主线：P2-T3 测试数据分析
-> 异常分支：P2-T2 测试问题处理 -> P2-T3 测试数据分析
```

## 当前实现

1. 课程首页：说明当前阶段从项目四样本进入项目二复制验证；
2. 项目视图：显示P2-T1主线、P2-T2条件分支、P2-T3分析输出；
3. 项目二内容样稿：展示三任务教材化学习段落、学生完成标准和教师带教用途；
4. 课程能力图谱：新增项目二19个详细节点的局部导航，并保留V2.1关系评审入口；
5. 教师视图：说明何时直接进入P2-T3、何时进入P2-T2；
6. 资源中心：展示测试任务单、设备检查表、测试软件示意图、LOG/GPS/报告模板等资源治理状态；
7. 出版/编辑视图：保留数据脱敏、软件截图重绘、平台接口未接入等质量门禁。

## 已知边界

1. P2-T3只是深样章候选，尚未形成任务级深样章页面；
2. P2-T2是异常处理分支，不得设计成全体学生固定必经步骤；
3. 专业阈值、测试流程、异常排查顺序仍需通信专业复核；
4. 真实LOG、GPS轨迹、设备照片和软件截图不能直接作为正式资源发布；
5. 没有接入真实学习记录数据库；
6. 没有接入真实AI助手；
7. 没有接入出版社真实平台接口；
8. 真实一线教师/学生试看尚未完成。
