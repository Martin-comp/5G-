## 当前定位

本样章是“3.5A-1两课时修订版”。它不推翻3.5A的课程能力图谱驱动结构，而是根据内部预评审和用户确认，把任务暂定为2课时，并在一线教师/学生试看前补齐几个关键短板：

1. 将任务统一为2课时、90分钟；
2. 学生首屏看到先做什么、交什么、怎样算完成，但不展示课时建议分配；
3. 每个案例都有完成标准和二次修正任务；
4. 学生反馈后必须写“我的修正句”，学习单分为“我的填写”和“参考表达”；
5. 课程能力图谱在学生端进一步转译为学习关系，不直接暴露节点编号；
6. 教师页保留2课时安排、教师试看说明、学生观察记录点、模拟学情和专业复核表。

## 内容边界

本版案例均为教学模拟案例。案例不伪装成真实项目，阈值为本课验收目标，不代表通用行业标准。

术语字典是配置化词条，不是真实AI助手。模拟学情是用于验证教师页信息架构的模拟数据，不是真实学生数据。

本版仍未接入出版社平台接口、学习记录数据库、真实批改服务或真实AI助手。学生修正句保存在浏览器本地状态中，只用于原型验证。
