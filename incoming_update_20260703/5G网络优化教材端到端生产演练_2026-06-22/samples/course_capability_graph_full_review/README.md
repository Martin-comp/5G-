# 完整课程能力图谱评审版

生成日期：2026-06-23  
入口：`index.html`

## 定位

本样本用于单独查看《5G网络优化教材（高级）》课程能力图谱是否需要优化。

当前采用“全课程框架完整 + 项目四任务2深度展开”的方式：

1. 覆盖6个项目、18个任务；
2. 呈现7个课程主链节点；
3. 展开P4-T2的8个详细能力节点；
4. 标注其他任务为待细化结构节点；
5. 展示关键跨层关系。

## 评审重点

1. 主链是否体现岗位工作过程，而不是目录换名；
2. 任务归属是否合理；
3. P4-T2八个详细节点是否过粗、过细或顺序不合理；
4. P4-T2的细化方式是否适合扩展到其他任务；
5. 图谱是否能支撑资源、学习活动和评价挂接。

## 已知边界

1. 当前不是专家复核后的最终图谱；
2. 其他17个任务尚未展开细粒度能力节点；
3. 跨层关系是基于教材结构和样章实践的当前推断；
4. 本页面是评审用可视化，不是正式平台组件。
