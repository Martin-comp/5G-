## 当前定位

本样章已从3.1“任务工作台 + 材料聚焦看板”升级为3.2“教材正文驱动样章”。它仍保留任务工作台、能力地图、材料区、学习记录、教师讲评和编辑审核，但主学习区不再只围绕材料条目组织，而是围绕学生能读懂的教材正文组织。

3.2当前核心变化：

1. 首屏以“网页好了，为什么还不能直接说优化成功”作为真实任务导入；
2. 学生先完成初步判断，再通过数据修正判断；
3. 中间区采用“段落导航 + 当前正文段落聚焦”，避免把全部正文堆成长页面；
4. 材料区保留4个入口：覆盖与质量、移动与保持、业务体验、媒体边界；
5. 每组数据都说明“能支持什么、不能说明什么”；
6. 课堂模式强调小组分工、课堂停顿点和汇报讲评；
7. 自学模式强调读数步骤、术语解释、句式支架和错误原因；
8. 能力地图节点可跳转到对应正文和材料；
9. 学生端不显示来源层级、后台字段或资源ID；
10. 编辑审核层集中显示来源层级、专业复核清单、发布风险和媒体处理建议。
