# 课程能力图谱V2.1关系可视化评审版

生成日期：2026-06-24  
入口：`index.html`

## 定位

本样本用于评审课程能力图谱节点之间的关系是否足够直观。

它不替代 `samples/course_capability_graph_v2_optimized/`，也不是整书级整体原型中的正式图谱。当前重点是验证三件事：

1. 四任务主链能否看清；
2. 点击节点后，前置、后续、支撑、回流关系能否看清；
3. 关系是否能回到结构化边表，便于后续治理和平台化。

## 数据来源

- `reports/课程能力图谱V2节点与映射表.csv`
- `reports/课程能力图谱V2关系边表.csv`
- 四张V0.2字段表中的 `relation_records`

## 交互说明

1. 默认进入 `P5T3-N06` 的节点邻域，只显示少量核心关系线，避免总览线团；
2. 可按直接递进、前置基础、支撑判断、问题回流、能力挂接、资源证据筛选；
3. 点击任意详细节点后进入“节点邻域”视图，优先看当前节点的一跳入边和出边；
4. 需要观察全局分布时，再切换“总览视图”；
5. 中间图只画当前筛选下可连接到页面节点的线；
6. 下方关系清单保留当前筛选结果的全部边。

## 已知边界

1. 当前是评审样本，不是专家复核定稿；
2. 资源证据边中包含原教材媒体资源编号，仍需媒体、版权和专业审查；
3. 总览视图不会一次性显示182条边，避免形成线团；
4. 若人工评审仍觉得不够直观，应先优化默认筛选和节点邻域表达，不应继续增加节点。
