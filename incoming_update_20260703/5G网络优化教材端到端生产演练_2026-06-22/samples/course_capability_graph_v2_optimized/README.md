# 课程能力图谱V2优化版

生成日期：2026-06-24  
入口：`index.html`

## 定位

本样本用于验证课程能力图谱是否从“教材目录映射”升级为“岗位工作过程图谱”。

V2相比上一版的主要变化：

1. 增加依据层：专业教学标准、岗位任务、数字教材标准、职业教育关键要素改革；
2. 主链改为岗位工作过程：明确场景与需求、组织测试、识读指标、定位问题、实施优化、验证效果、持续复盘；
3. 项目和任务降为能力单元的承载场景；
4. 每个能力单元补齐资源类型、学习活动、评价产出和审核状态；
5. P4-T2继续作为深展开样板；
6. P2-T3、P5-T3、P6-T2已加入迁移试拆，用于验证V2方法能否跨任务复用；
7. 页面新增“四任务链条验证”，展示“数据分析 -> 结果验证 -> 持续提升 -> 信令复盘”的内部能力闭环。

## 交互说明

节点详情采用固定右侧抽屉：

1. 默认不占据图谱主体布局；
2. 点击岗位工作过程、能力单元或详细能力节点后，从屏幕右侧打开；
3. 桌面端打开后仍可直接点击其他节点，详情内容随点击切换；
4. 抽屉可通过右上角关闭按钮关闭；
5. 移动端抽屉按屏幕宽度自适应，优先保证详情可读。

## 已知边界

1. 仍是评审优化版，不是专家复核最终版；
2. P2-T3、P5-T3、P6-T2已完成方法性试拆，但尚未形成完整学生端教材正文和可运行任务页面；
3. 当前详细节点共30个，只覆盖四个代表任务，其他任务尚未全部拆到P4-T2这种细粒度；
4. 标准依据目前为摘要级挂接，未逐条绑定标准原文；
5. 专业阈值、案例数据、信令判断逻辑和结论口径仍需通信专业教师复核；
6. P5-T3、P6-T2存在较多媒体重绘和专业高风险节点，不能把“有条件成立”写成“专家审核通过”。
