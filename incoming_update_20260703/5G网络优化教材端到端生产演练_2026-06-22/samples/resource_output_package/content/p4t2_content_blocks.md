# 任务2：5G网络优化结果验证（结构化内容块样本）

## 任务导入

用户在微信视频、直播等场景中遇到卡顿、掉线或时延较大时，需要从无线覆盖、切换、时延、速率、容量、掉线等维度判断网络优化结果是否达成。

## 任务目标

学习者完成本任务后，应能够：

1. 判断覆盖优化结果是否满足目标；
2. 判断切换优化是否改善业务连续性；
3. 判断时延、速率、容量、掉线等指标是否达到优化预期；
4. 使用仿真软件或测试数据完成优化前后对比；
5. 输出包含证据链的优化结果验证结论。

## 核心知识块

### 覆盖优化结果验证

关键指标包括 SS-RSRP、SS-SINR、弱覆盖、越区覆盖、交叉覆盖、导频污染等。验证时应同时检查工程参数、发射功率、波束配置、邻区关系和规划改造需求。

### 切换优化结果验证

关键知识包括 A1/A2/A3/A4/A5/A6/B1/B2 测量事件、SA 切换流程、NSA 带 SN/不带 SN 切换流程，以及切换失败阶段定位。

### 端到端性能验证

围绕时延、速率、容量、掉线等典型场景，对比优化前后关键 KPI、参数配置、测试截图和业务体验，形成可复核证据。

## 实训任务单样本

任务：在仿真软件中完成一次端到端优化结果验证。

输入：优化前指标、优化后指标、工程参数、无线参数、仿真截图。

输出：

1. 优化对象分类；
2. 指标变化表；
3. 参数调整说明；
4. 结果是否达成判断；
5. 后续优化建议。

## 待专家审核点

1. 覆盖阈值的运营商来源和适用场景；
2. SA/NSA 切换流程图与当前 5G 网络版本的一致性；
3. 时延、速率、容量、掉线的判定指标是否足够完整；
4. 仿真软件截图是否可公开复用；
5. 测评题是否能真实评价高级网优能力。
