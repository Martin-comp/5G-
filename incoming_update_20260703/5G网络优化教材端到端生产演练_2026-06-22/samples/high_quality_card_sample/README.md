# 高质量卡片式数字教材样章

样章对象：项目四 / 任务2：5G网络优化结果验证  
入口文件：`index.html`

## 使用方式

直接用浏览器打开：

`/Users/ny/Downloads/5G网络优化教材端到端生产演练_2026-06-22/samples/high_quality_card_sample/index.html`

页面包含三个视图：

1. 学生学习：11 张学生学习卡、任务工作台、课堂/自学模式、任务单和即时反馈；
2. 教师讲评：独立教师卡、模拟学情、错误分布和讲评建议；
3. 资源追踪：卡片与能力节点、来源、学习证据和审核状态映射。

## 样章2.0修正点

1. 教师卡已从学生学习路径移出，只在教师讲评视图和资源追踪中保留；
2. 学生端从单纯翻页改为“任务工作台 + 学习资源导航”；
3. 增加课堂模式和自学模式，自学模式提供更完整的解释、误区和下一步提示；
4. 右侧“学习证据”改为“我的证据链”，显示问题判断、引用证据、缺失证据和最终结论状态；
5. 仿真截图卡已重写为媒体审查与证据边界卡，不再默认截图可直接用于学生自学；
6. 新增媒体资源审查表，逐项评估原教材图片是否保留、标注、替换或重绘。
