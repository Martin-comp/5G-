# 政策与数字教材标准依据摘要

生成日期：2026-06-22

## 1. 教育部等七部门数字教材指导意见

本地文件：`教育部办公厅等七部门关于加强数字教材建设和管理的指导意见(1).pdf`  
OCR 文本：`local_policy_text/教育部办公厅等七部门关于加强数字教材建设和管理的指导意见_ocr.txt`

可用于本次演练的关键约束：

1. 数字教材被界定为依据国家课程标准或教学标准开发、正式出版、用于学校教育教学活动的数字化核心教学材料，具有多模态、强交互、智能化等特点。
2. 职业教育数字教材试点强调把生产、服务和管理现场的标准、资源、案例等转化为教学资源和应用场景。
3. 数字教材基础建设要围绕内容呈现、标准研制、技术适配、安全规范、资源共享、版权保护、应用场景、评价方法等关键问题开展。
4. 数字教材标准体系优先覆盖信息模型、内容规范、技术格式规范、数据接口、质量评价与效果评估。
5. 数字教材要加强审核管理，落实“凡编必审”，确保政治方向、价值导向、内容科学、技术先进、适教利学，并探索全生命周期管理与迭代更新。
6. 数字教材服务平台要兼容、可对接，支持跨平台使用，同时满足安全可靠、自主可控、版权保护和数据互联互通要求。

对本次端到端演练的含义：

- 不能只生成“漂亮页面”，必须同时生成标准化资源、审核依据、元数据、版权与平台适配清单。
- AI 生成资源只能作为待审稿件，必须进入人工/人机协同审核流程。
- 课程能力图谱应服务于“标准、资源、案例、任务、评价”之间的结构化连接，而不是只做知识点目录。

## 2. “人工智能+教育”行动计划

来源：教育部等五部门《“人工智能+教育”行动计划》  
本地文本：`web_text/ai_education_action_2026.txt`  
原始链接：<https://www.moe.gov.cn/srcsite/A16/s3342/202604/t20260410_1433240.html>

可用于本次演练的关键约束：

1. 人工智能应推动智能技术与教育全要素融合、全过程贯通、全场景覆盖。
2. 职业教育传统专业要围绕人工智能影响进行升级转型，联合行业企业更新课程体系、共建实习实训实践基地。
3. 支持课前、课中、课后全过程智能教学系统应用，支撑多模态教学资源自动生成、方案优化和教学过程模拟。
4. 鼓励强交互虚拟仿真实验、个性评价反馈、学生知识能力素质图谱、动态学习路径。
5. 试点研发数字教材，丰富数字教育资源形态，构建沉浸式教学空间和人机协同教学模式。
6. 强调人工智能教育应用安全审核、生成合成内容标识、数据安全和可信可控。

对本次端到端演练的含义：

- 工具链应覆盖内容生成、资源重构、学习路径、评价反馈和数据回收，不应只停留在排版转换。
- 直接呈现样本应体现学习路径、任务推进、互动测评和学习数据事件设计。
- AI 生成内容要标识来源、版本和审核状态。

## 3. 职业教育教学关键要素改革

来源：教育部办公厅等五部门《关于实施职业教育教学关键要素改革 推动高技能人才培养的意见》及教育部解读  
本地文本：

- `web_text/vocational_key_elements_2026.txt`
- `web_text/vocational_key_elements_interpretation_2026.txt`

原始链接：

- <https://www.moe.gov.cn/srcsite/A07/zcs_zhgg/202602/t20260212_1428773.html>
- <https://www.moe.gov.cn/jyb_xwfb/s271/202602/t20260212_1428781.html>

可用于本次演练的关键约束：

1. 职业教育改革聚焦专业、课程、教材、教师、实习实训五个关键要素联动改革。
2. 课程要“新”，要求科学设计课程组合，绘制课程能力图谱。
3. 教材要“活”，要求推进教材形态多样化，面向行业紧缺领域开发教材。
4. 企业技术标准、生产资源、职业场景要开放并转化为教育教学标准和人才培养标准。
5. 改革要求按产业环节、生产流程、职业逻辑系统推进，而不是按传统学科章节孤立建设。

对本次端到端演练的含义：

- 能力图谱是数字教材的关键纽带，应连接岗位任务、课程内容、教材资源、实训活动和评价证据。
- 本教材应从“项目-任务”结构进一步转化为“岗位任务-能力单元-知识技能点-资源-测评”的图谱。
- 生产工具链必须支持低输入场景下的标准补全和产业资料补全。

## 4. 数字教材出版与技术标准

本次纳入的本地标准文本：

- T/CADPA 55-2024《高等教育数字教材核心元数据》
- T/CADPA 56-2024《高等教育数字教材封面与版本记录》
- T/CADPA 57-2024《高等教育数字教材封装要求》
- T/CADPA 58-2024《高等教育数字教材出版平台接口技术要求》
- T/CADPA 64-2026《高等教育数字教材出版业务流程》
- T/CADPA 65-2026《高等教育数字教材出版平台基本功能要求》
- T/CADPA 66-2026《高等教育数字教材内容要素技术要求》
- T/CADPA 67-2026《高等教育数字教材质量要求与检测》

可用于本次演练的关键约束：

1. 出版流程包含选题策划与论证、内容编写、资源制作与集成、内容审校与排版、申请书号、测试与质检、封装发布、管理更新。
2. 平台能力至少涉及出版功能、发行功能、服务功能、系统功能，支持内容编辑、内容审核、封装发布、阅读学习、学习服务、数据服务和接口服务。
3. 内容要素包括文本、图片、表格、公式、音频、视频、交互资源等，扩展资源应有明确标识、技术要求和运行说明。
4. 封装要求包括数字教材标识文件、内容清单文件、元数据文件、版权文件、封面文件、组织结构集文件、内容文件集、资源文件集等。
5. 接口要求包括基础信息类接口、交易类接口、使用数据类接口；使用数据类接口可输出学习、测验、章节考评等使用情况。
6. 质量检测至少覆盖内容质量、编校质量、技术质量、应用质量，并形成检测记录和检测报告。

对本次端到端演练的含义：

- 资源输出样本应至少包含资源清单、元数据、版权状态、章节关联、能力关联、题目关联和审核状态。
- 直接呈现样本应至少具备目录、正文、图片/表格、互动测评、学习进度和事件埋点设计。
- 标准封装样本可先做“准 DTB 包结构”，在未获得出版社平台规范前不假称已达到某平台正式入库要求。
