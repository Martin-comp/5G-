# 课程能力图谱依据摘要

生成日期：2026-06-22

## 1. 政策依据

职业教育教学关键要素改革文件明确提出“课程要新”，要求科学设计课程组合，绘制课程能力图谱；同时要求“教材要活”，推动教材形态多样化。教育部解读进一步强调，要按产业环节、生产流程、职业逻辑推进专业、课程、教材、教师、实习实训联动改革。

对本项目的含义：

- 课程能力图谱不是知识图谱的改名，也不是教材目录的可视化。
- 它应以岗位任务和职业能力为牵引，把课程标准、教材内容、数字资源、实训任务、测评证据连接起来。

## 2. 专业教学标准依据

现代通信技术、现代通信工程专业教学标准均把“移动通信网络规划与优化”作为重要课程/能力领域，明确典型任务包括站点勘察、网络测试、数据采集、后台分析、信令分析、优化方案制订、优化实施和报告输出。

对本项目的含义：

- 《5G网络优化教材（高级）》的能力图谱主链应是工作过程链，而不是章节顺序链。
- 建议主链为：信息采集 -> 网络测试 -> 信息管理 -> 优化实施 -> 结果验证 -> 性能提升 -> 信令分析。

## 3. 数字教材标准依据

T/CADPA 系列标准要求数字教材具备元数据、内容清单、组织结构、资源文件、版权文件、平台接口、使用数据和质量检测等要素。

对本项目的含义：

- 能力图谱节点应成为资源组织和平台接口的中间层。
- 每个节点至少应能关联：教材位置、知识点、技能点、资源、题目、实训任务、评价方式、审核状态、使用数据事件。

## 4. 本次能力图谱建议模型

建议采用八类节点：

1. `program_standard`：专业教学标准条目；
2. `course_goal`：课程目标；
3. `job_task`：岗位/工作任务；
4. `capability`：能力单元；
5. `knowledge`：知识点；
6. `skill`：技能点；
7. `resource`：数字资源；
8. `assessment`：测评与评价证据。

建议采用十类关系：

1. `aligns_to`：对齐标准；
2. `requires`：前置依赖；
3. `contains`：包含；
4. `supports`：资源支撑；
5. `assesses`：测评评价；
6. `evidenced_by`：证据支撑；
7. `remediates`：补救学习；
8. `extends`：拓展；
9. `generated_from`：由教材输入生成；
10. `needs_review`：需专家/编辑审核。

## 5. 本次端到端样本的图谱约束

项目四任务2“5G网络优化结果验证”的能力图谱应至少覆盖：

1. 能识别覆盖、切换、时延、速率、容量、掉线等优化结果验证对象；
2. 能解释 SS-RSRP、SS-SINR、切换事件、时延、速率、容量等关键指标；
3. 能使用仿真/测试结果判断优化是否达成；
4. 能把优化前后参数、指标、截图和结论形成证据链；
5. 能通过测评题和实训任务验证学习者是否具备分析、判断和报告能力。
