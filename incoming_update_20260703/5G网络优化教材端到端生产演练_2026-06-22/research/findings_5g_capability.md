## 1. 教育部现代通信技术专业教学标准（高职专科，2025）

来源：教育部职业教育专业教学标准公开附件  
本地文件：`5g_sources/现代通信技术专业教学标准_高职专科_2025.pdf`  
原始链接：<https://www.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/gdzyjy_zk/zk_dzyxxdl/dzxxdl_txl/202502/P020250207535356609887.pdf>

与本教材相关的关键点：

1. 专业面向信息通信工程勘察与设计、施工与监理，信息通信网络运行维护管理及优化等岗位群。
2. 职业类证书字段列有网络系统建设与运维、5G 基站建设与维护、5G 移动通信网络部署与运维等方向，但本次不采用 1+X 作为依据。
3. 培养规格明确要求学生掌握移动通信网络测试、数据采集及分析、优化方案制订及实施等技术技能，具备移动通信网络运营、维护与优化实践能力。
4. 专业核心课程包括移动通信网络建设与部署、移动通信网络规划与优化等领域。
5. “移动通信网络规划与优化”典型工作任务包括网络规划、网络优化、前台测试、后台优化软件数据分析、给出解决方案并完成优化。
6. 主要教学内容与要求包括无线传播模型、路径损耗、覆盖规划、容量规划、站点勘察、网络测试、信令流程分析、常见优化指标分析，以及覆盖、干扰、切换、吞吐量等常见故障分析处理。

对本教材的定位判断：

- 《5G网络优化教材（高级）》应归入“移动通信网络规划与优化”方向的核心/拓展教材。
- 能力图谱应围绕“测试采集 -> 指标分析 -> 问题定位 -> 优化方案 -> 参数/工程实施 -> 结果验证 -> 报告输出”展开。

## 2. 教育部现代通信工程专业教学标准（职教本科，2025）

来源：教育部职业教育专业教学标准公开附件  
本地文件：`5g_sources/现代通信工程专业教学标准_职教本科_2025.pdf`  
原始链接：<https://www.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/gdzyjy_bk/bk_dzyxxdl/dzxxdl_txl/202502/P020250207568583286035.pdf>

与本教材相关的关键点：

1. 专业面向信息通信工程勘察、规划、设计、监理与施工，以及通信设备与网络的运行、维护、管理与优化。
2. “移动通信网络规划与优化”要求学生具备链路预算、覆盖规划、容量规划、站点勘察、路测、信令分析、常见网络优化问题处理、优化报告输出等能力。
3. 实训场所要求中明确移动通信实训室应配备移动通信系统设备和移动通信网络优化实训平台。
4. 教材要求体现行业新技术、新规范、新标准、新形态，并可通过数字教材、活页式教材等形式呈现。

对本教材的定位判断：

- 若面向高级层级，本教材不仅要支持操作训练，还要支持综合问题诊断、信令分析、优化报告和复杂场景决策。
- 数字教材样本应加入“证据链”：指标数据、截图、参数变化、优化前后对比、诊断结论。

## 3. 国家职业技能标准：信息通信网络运行管理员（2019年版）

来源：技能人才评价证书全国联网查询系统 / 国家职业标准接口  
官方查询接口结果：`occupation_sources/osta_skill_standard_query.json`  
官方 PDF：`occupation_sources/信息通信网络运行管理员国家职业技能标准_2019_官方.pdf`  
接口入口：<https://www.osta.org.cn/skillStandard>

与本教材相关的关键点：

1. 职业定义为从事信息通信网络运行配置管理、性能管理、优化管理和故障排除等工作的人员。
2. 职业能力特征包括组织、理解、判断、学习、沟通、分析和解决问题能力。
3. 工作要求覆盖信息通信网络性能管理、故障管理、资源管理、配置管理、优化管理、培训指导等。
4. 高等级要求中明确网络优化管理，包括分析网络运行状况、提出网络优化建议、制定网络优化方案、评估优化效果并完善优化方案。

对本教材的定位判断：

- 国家职业标准可以作为“职业活动边界”和“高级能力层级”的依据。
- 该标准不提供 5G 细分知识点，因此不能替代专业教学标准和通信行业技术规范。

## 4. 全国职业院校技能大赛 5G组网与运维赛项规程（2023）

来源：全国职业院校技能大赛赛项规程公开附件  
本地文件：`competition_sources/GZ035_5G组网与运维赛项规程_2023.pdf`  
原始链接：<https://chinaskills-jsw.oss-cn-beijing.aliyuncs.com/2023nssxgzs8/20230510204344146.pdf>

与本教材相关的关键点：

1. 赛项覆盖 5G 公共网络规划部署与开通、5G 公共网络运维与优化、5G 专用网络组网与运维、职业素养。
2. 典型任务包括拓扑规划、覆盖规划预算、速率容量计算、勘察设计、工程参数规划、设备安装、配置、调试、开通。
3. 运维与优化任务包括告警分析、设备参数配置维护、开通调试、切片优化、CQT/DT 测试、重选/切换/漫游等移动性管理指标优化。
4. 规程强调设计、安装、调试、优化和运维一体化任务，并以过程性操作和结果性指标共同评价。

对本教材的定位判断：

- 竞赛规程可作为“实训任务形态”和“综合项目组织方式”的参照。
- 它不是课程标准，不能直接替代专业教学标准；但可帮助数字教材样本设计更接近真实工作过程。
