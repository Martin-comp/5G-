# 跨设备复制与校验清单

生成日期：2026-06-29  
用途：把项目复制到另一台电脑后，确认新Codex可以稳定接手。

## 1. 复制方式

必须复制整个目录：

```text
5G网络优化教材端到端生产演练_2026-06-22
```

不要只复制：

1. 单个HTML；
2. 单个Word；
3. `samples/` 子目录；
4. `reports/` 子目录；
5. 当前看起来最新的几个文件。

推荐复制方式：

1. AirDrop整个目录；
2. 移动硬盘或U盘复制整个目录；
3. 局域网文件共享复制整个目录；
4. 压缩成zip后复制，再在新电脑完整解压。

不建议在复制前整理、改名或移动目录结构。

## 2. 新电脑上的基础检查

在新电脑终端中执行：

```bash
PROJECT_ROOT="/新电脑上的实际路径/5G网络优化教材端到端生产演练_2026-06-22"
cd "$PROJECT_ROOT"

find . -type f | wc -l
du -sh .
```

期望结果：

1. 文件数量接近 `1228`；
2. 目录规模接近 `237M`。

如果文件数量明显偏少，说明复制不完整，应重新复制整个目录。
