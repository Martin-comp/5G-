## 1. 本文件夹的作用

`00_治理与索引` 是本任务的外部记忆层。后续继续执行任务时，应先读取本文件夹，再读取具体报告或样章代码。

本文件夹不替代原成果文件，也不移动原文件。它负责回答五个问题：

1. 现在有哪些资产；
2. 哪些资产是主线，哪些只是过程记录；
3. 已经形成了哪些关键原则和决策；
4. 当前任务推进到哪里；
5. 下一步应该从哪里接上。

## 6. 继续执行前的硬性提醒

1. 不要把2.0原型当成最终方向；
2. 不要继续堆叠漂亮卡片来替代教材性；
3. 不要把学生界面写成生产工具或数据平台；
4. 不要让教师卡进入学生学习路径；
5. 不要把仿真截图占位符当成媒体治理结果；
6. 不要使用1+X作为依据；
7. 不要只做前端样式而忽略内容完整度、学习任务和教师可用性。
8. 不要把大纲、标题和资源入口拼成教材；当前必须优先保证学生端教材正文成立。
9. 不要被输入教材本身限制住；发现原教材薄弱、过时或不适合学生学习时，应基于可信来源和专业依据纠偏补强。
10. 不要只依赖对话记忆维护治理文件；新增资产、决策、原则、阶段变化时必须按 `治理执行规程.md` 更新治理层。
11. 不要让正式资源、活动、评价或页面脱离课程能力图谱主数据；没有图谱挂接的内容只能作为探索草稿，不应进入正式资源包或数字教材呈现层。
