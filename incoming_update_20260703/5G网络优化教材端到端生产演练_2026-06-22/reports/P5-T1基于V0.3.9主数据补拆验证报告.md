# P5-T1基于V0.3.9主数据补拆验证报告

生成日期：2026-06-26  
适用对象：项目五 / 任务1：5G全网性能指标采集  
基线版本：课程能力图谱主数据V0.3.9  
报告定位：第十类普通任务受控补拆验证结果，不是专家定稿，不直接改写V0.3.9主数据。

## 1. 结论

P5-T1适合作为“全网指标采集与指标口径治理类任务”的增量验证对象。本轮建议将P5-T1拆为8个详细能力节点，作为V0.3.9之后的候选增量。

本轮补拆结果为：

1. 8个详细能力节点；
2. 41条关系增量；
3. 24条资源活动评价挂接；
4. 12条输入输出物治理记录；
5. 16条V0.4风险治理扩展记录。

P5-T1的核心价值不是让学生背指标公式，而是形成一条可学习、可操作、可评价的数据采集链：

```text
明确采集任务
-> 区分指标口径、周期和数据源
-> 分组采集接入、保持/移动性、资源/可用、覆盖/互操作/干扰指标
-> 判断数据质量和证据可信度
-> 形成全网指标采集包
-> 支撑P5-T2提升实施和P5-T3验证
```

## 3. 原文处理判断

P5-T1原文包含五类内容：

1. 任务情境：NSA/SA网络中采集哪些性能指标来评估整体服务质量；
2. 指标体系：KPI/PI、采集途径、指标口径、公式和计数器；
3. 指标类别：接入、保持性、移动性、资源、可用、覆盖、互操作和干扰；
4. 任务实施：登录仿真实训系统、进入数据中心、采集无线侧指标；
5. 测试和案例：过去一小时指标提取、接通率相关指标采集案例、难点提示。

本轮没有把每个指标公式拆成独立节点。原因是这些对象更适合进入资源卡、指标表、术语解释、工作单或风险治理层。能力节点应表达学生必须完成的稳定职业动作：明确任务、定口径、采数据、查质量、交接结果。

## 4. 详细能力节点

本轮形成以下8个候选详细能力节点：

| 节点 | 名称 | 主要训练点 | 评价产出 |
| --- | --- | --- | --- |
| P5T1-N01 | 明确全网性能指标采集任务与服务质量问题 | 判断本次采集要回答什么服务质量问题 | 全网指标采集任务单 |
| P5T1-N02 | 区分KPI/PI、指标口径与统计周期 | 区分指标名称、公式、统计周期、区域范围和数据源 | 指标口径说明表 |
| P5T1-N03 | 采集接入类指标并核对关键计数器 | 提取RRC、NG、QoS Flow、PDU Session、无线接通率等接入类指标 | 接入类指标采集记录 |
| P5T1-N04 | 采集保持性与移动性指标 | 提取掉线、异常释放、切换成功率等指标 | 保持/移动性指标采集记录 |
| P5T1-N05 | 采集资源类与可用类指标 | 提取流量、PRB利用率、连接用户数、小区可用率等指标 | 资源/可用类指标采集记录 |
| P5T1-N06 | 采集覆盖、互操作与干扰类指标 | 提取MR覆盖、弱覆盖、越区覆盖、4/5G互操作和干扰相关指标 | 覆盖/互操作/干扰指标采集记录 |
| P5T1-N07 | 判断数据质量与采集证据可信度 | 检查数据源、时间窗、样本量、缺失、异常和截图/导出表证据 | 数据质量检查单 |
| P5T1-N08 | 形成全网指标采集包并连接后续任务 | 汇总采集结果，标明进入提升实施、验证基线或二次补采的内容 | 全网性能指标采集包 |

该结构控制在8个节点，避免P5-T1退化为指标公式清单。

## 5. 关系设计

本轮关系设计分为五类：

1. 任务拆分：`P5-T1` 拆分为8个详细能力节点；
2. 内部关系：N01到N02为任务到口径，N03至N06为并列采集分支，N07做数据质量检查，N08做采集包交接；
3. 能力挂接：8个节点均主挂 `AU-09 全网性能提升与复测`；
4. P5内部支撑：P5-T1详细节点支撑P5-T3的验证口径、KPI对比基线、接入/保持/移动性/资源/可用类验证、未闭环入口和验证报告；
5. 跨任务支撑：P2-T3、P3-T2、P4-T2、P6-T2对P5-T1的指标读法、查询入口、判断依据和复杂问题入口提供前置支撑。

关系数量为41条。所有端点均应能回溯到V0.3.9既有节点、能力单元、任务级节点或本轮新增节点。

## 10. 风险治理

本轮形成16条V0.4风险治理扩展记录，覆盖8个详细能力节点、3组媒体对象、3组工作表/评价对象、1组输出物和1组原文来源。

重点风险包括：

1. 指标口径风险：KPI/PI、统计周期、区域范围、样本量和计数器不能由AI直接定稿；
2. 专业术语风险：RRC、NG、QoS Flow、PDU Session、PRB、MR、RSRP、SINR等解释需专业复核；
3. 阈值风险：弱覆盖、MR覆盖率、覆盖门限、干扰判断等不能写成通用定值；
4. 数据风险：全网指标、平台截图、网管导出和区域统计可能涉及真实运营数据；
5. 媒体风险：image303-image317均需媒体审查或重绘；
6. 学生可懂性风险：后续正文不能退化为指标百科或公式堆叠；
7. 任务边界风险：P5-T1只做采集和口径治理，不替代P5-T2实施和P5-T3验证。

所有发布、专业、媒体、学生正文、平台和教学验证门禁均保持未通过状态。
