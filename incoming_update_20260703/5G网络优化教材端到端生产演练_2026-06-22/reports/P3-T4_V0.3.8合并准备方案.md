## 3. 合并范围

### 3.1 节点主数据

建议将P3-T4增量样表中的6个详细能力节点纳入V0.3.8候选节点主表：

1. `P3T4-N01 明确参数设置任务与变更依据`
2. `P3T4-N02 识别参数对象与影响范围`
3. `P3T4-N03 制定邻区添加、删除或调整方案`
4. `P3T4-N04 完成教学仿真参数设置并记录证据`
5. `P3T4-N05 核查设置结果、风险与回退条件`
6. `P3T4-N06 形成参数变更记录并衔接复测`

合并规则：

1. 不改写V0.3.7中已有的 `P3-T4` 任务骨架节点。
2. 不改写 `AU-04`、`AU-06` 和 `AU-07` 能力单元节点。
3. 保留6个新增节点的 `audit_status`、`review_required_type`、`risk_level`、`media_handling_status` 和 `professional_risk_type`。
4. 保留 `source_maturity=increment_trial` 和 `v03_maturity=increment_trial`。
5. 不把节点状态改成专业复核通过、媒体审查通过、工程授权通过或可发布。

预计节点数量：

`157 + 6 = 163`

### 3.2 关系主数据

建议将P3-T4关系增量样表中的36条关系纳入V0.3.8候选关系主表。

关系类型覆盖：

1. 任务拆分详细节点：6条。
2. 内部递进：5条。
3. 前置基础：若干条，覆盖P3-T2、P3-T3、P3-T1等对P3-T4的进入支撑。
4. 后续递进：覆盖P4-T1、P4-T2、P5-T3和P6-T2等复测、实施和复盘路径。
5. 支撑判断：覆盖P2-T3、P4-T1、P4-T2等对参数设置判断的支撑。
6. 能力挂接：覆盖AU-04、AU-06和AU-07。
7. 资源证据：覆盖媒体审查对象对N04的支撑。

合并规则：

1. 不删除V0.3.7中已有P3-T2、P3-T3、P4-T1、P4-T2、P5-T3和P6-T2相关关系。
2. 新增P3-T4详细节点层关系，用于补齐项目三“运行监控 -> 参数检查 -> 参数设置 -> 复测交接”的链条。
3. `P3T4-N04` 必须保留教学仿真或重绘界面边界，不得被解释为真实生产网管操作。
4. `P3T4-N06 -> P4-T1/P4-T2/P5-T3/P6-T2` 的后续路径进入候选关系表，但必须保留待专业复核状态。
5. 能力挂接关系进入候选关系表，但不改变AU-04、AU-06和AU-07能力单元定义。

预计关系数量：

`392 + 36 = 428`

## 4. V0.4风险治理处理

P3-T4的12条V0.4风险治理扩展记录不并入V0.3.8四张主数据表。

处理方式：

1. 继续作为旁挂式风险治理记录。
2. 在V0.3.8合并说明中列为P3-T4风险治理依据。
3. 在输入输出物治理清单中保留 `P3-T4风险治理扩展增量样表V0.4.csv`。
4. 后续若形成全局V0.4风险治理汇总表，再决定是否并入汇总。

不得做的事：

1. 不把 `overall_publish_gate_status=not_ready` 改为通过。
2. 不把 `professional_gate_status=pending` 改为通过。
3. 不把 `media_gate_status=pending` 改为通过。
4. 不把教学仿真、教材截图、参数样例或AI推断写成真实工程授权或行业通用结论。

## 5. 合并前结构检查

P3-T4增量已经完成以下检查：

1. 新增节点ID唯一，未与V0.3.7既有节点冲突。
2. 新增关系ID唯一，未与V0.3.7既有关系冲突。
3. 新增挂接ID唯一，未与V0.3.7既有挂接冲突。
4. 新增资产ID唯一，未与V0.3.7既有输入输出物治理记录冲突。
5. 关系端点均可回溯到V0.3.7既有节点、P3-T4新增节点或P3-T4新增资源挂接对象。
6. 挂接节点均可回溯到P3-T4新增详细能力节点。
7. V0.4风险治理记录均可回溯到新增节点、新增资源对象或新增输入输出物治理对象。
8. 输入输出物路径已复核，无阻断结构错误。

因此，合并准备阶段不需要先做P3-T4 V0.3.7A修订。

## 6. 合并后必须保留的门禁

若后续生成V0.3.8候选主数据，必须保留以下门禁：

1. 专业复核门禁：Massive MIMO、邻区、NSA锚点、A2门限、QCI、SS-RSRP、SS-SINR、回退条件和复测分流规则。
2. 媒体审查门禁：原教材网管截图、参数表截图、案例截图和非通用仿真软件界面。
3. 工程授权门禁：参数设置、邻区删除、门限调整和锚点策略不能被写成真实生产操作授权。
4. 数据安全门禁：站点、业务承载、配置参数、信令截图和网管界面可能涉及敏感信息。
5. 学生正文门禁：当前不是教材正文，不能说明学生已经能直接学懂。
6. 平台门禁：当前没有出版社平台接口、学习记录数据库、真实仿真平台或AI助手接入。
7. 教学验证门禁：当前没有真实一线教师和学生试用数据。
