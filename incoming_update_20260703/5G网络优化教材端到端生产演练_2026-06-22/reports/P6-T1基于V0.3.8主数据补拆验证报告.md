生成日期：2026-06-26  
适用对象：项目六 / 任务1：5G关键信令流程及解析  
基线版本：课程能力图谱主数据V0.3.8  
报告定位：第九类普通任务受控补拆验证结果，不是专家定稿，不直接改写V0.3.8主数据。

## 1. 结论

P6-T1适合作为“高专业门槛流程类知识”的增量验证对象。本轮建议将P6-T1拆为8个详细能力节点，作为V0.3.8之后的候选增量。

本轮补拆结果为：

1. 8个详细能力节点；
2. 46条关系增量；
3. 24条资源活动评价挂接；
4. 12条输入输出物治理记录；
5. 16条V0.4风险治理扩展记录。

P6-T1的核心价值不是让学生背诵信令名称，而是帮助学生形成一条可学习、可操作、可评价的基础链条：

```text
4G/5G差异
-> 5G SA注册流程
-> 注册关键消息字段
-> PDU会话建立
-> MIB/SIB1系统消息
-> RRCReconfiguration场景
-> 工具证据入口
-> 5G重选到4G小案例
-> 支撑P6-T2复杂信令问题复盘
```

## 3. 原文处理判断

P6-T1原文包含四类内容：

1. 基础差异：4G/5G注册、连接、业务发起、切换、位置更新、寻呼和短消息差异；
2. 关键流程：5G SA注册流程、PDU会话建立流程；
3. 消息与字段：Registration request、RRCSetupRequest、RRCSetup、RRCSetupComplete、Registration accept/complete、MIB、SIB1、RRCReconfiguration；
4. 工具和案例：信令分析界面、地图窗口、信令窗口、邻区窗口、无线参数窗口、吞吐率窗口，以及5G重选到4G案例。

本轮没有把每条消息、每个信元、每张截图拆成独立节点。原因是这些对象更适合进入资源、活动、评价或风险治理层。能力节点应表达学生必须完成的稳定学习动作：串流程、读字段、找证据、判断场景、形成小案例证据链。

## 5. 关系设计

本轮关系设计分为六类：

1. 任务拆分：`P6-T1` 拆分为8个详细能力节点；
2. 内部递进：从4G/5G差异到注册流程、消息字段、PDU会话、系统消息、RRC重配、工具证据和小案例；
3. 能力挂接：8个节点均主挂 `AU-10 信令分析与复杂问题复盘`，并按节点连接 `AU-03`、`AU-07`、`AU-09`；
4. P6内部支撑：P6-T1详细节点下沉支撑P6-T2的接入排查、问题分类、切换证据链、任务材料定位和复盘报告；
5. 跨任务支撑：P5-T3未闭环入口、P4-T2移动性指标、P2-T3指标读法进入P6-T1流程学习和证据定位；
6. 资源证据：每个节点挂接一个媒体审查对象，明确需要重绘、标注或禁用。

关系数量为46条。所有端点均应能回溯到V0.3.8既有节点、本轮新增节点、能力单元或本轮新增资源审查对象。
