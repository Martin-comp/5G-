# 高质量卡片式样章原型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于 12 张完整学习卡片，制作一个可直接打开的高质量数字教材样章原型，用于验证学生学习、任务提交、反馈讲评和教师视图。

**Architecture:** 采用静态 HTML/CSS/JS 实现，不依赖后端和构建工具。资源层读取本轮已形成的卡片内容、卡片清单和教材图片，页面层提供学生端学习路径、证据判断、结构化任务单、即时反馈和教师讲评样例。

**Tech Stack:** HTML5、CSS3、原生 JavaScript、浏览器本地存储、本地图片资源。
