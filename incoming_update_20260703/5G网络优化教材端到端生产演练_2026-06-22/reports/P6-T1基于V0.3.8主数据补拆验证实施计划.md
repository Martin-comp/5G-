计划对象：项目六 / 任务1：5G关键信令流程及解析  
依据基线：课程能力图谱V0.3.8当前推荐主数据

当前定位：实施计划，不是补拆结果，不是主数据合并说明，不是学生端教材正文。

## 1. 本轮目标

本轮目标是验证课程能力图谱V0.3.8是否能够承载“高专业门槛流程类知识”的图谱化、教材化和活动化组织。

P6-T1不同于P6-T2：

| 任务 | 当前定位 | 不应混淆的边界 |
| --- | --- | --- |
| P6-T1 5G关键信令流程及解析 | 信令流程、关键消息、系统消息、工具入口和基础案例的先修支撑 | 不能拆成协议名词清单，也不能直接写成复杂问题复盘 |
| P6-T2 5G信令问题分析及优化 | 覆盖、接入、切换、掉线等复杂问题的信令复盘 | 不能反向替代P6-T1的基础流程学习 |

本轮只做P6-T1受控补拆验证，先形成实施计划，再进入补拆验证报告和增量样表制作。当前不制作页面、不生产资源包、不合并主数据、不拆解工具链模块。

## 2. 输入材料诊断

P6-T1原教材范围为 `extracted/textbook.md` lines 9638-10065，对应 `task_inventory.csv` 中的统计：

| 项目 | 数量 |
| --- | ---: |
| 原文行数 | 428 |
| 结构小节 | 8 |
| 图片数量 | 25 |
| 表格数量 | 0 |
| 随堂测试 | 3 |
| 经典案例 | 1 |

原教材内容包括：

1. 4G/5G信令过程差别；
2. 5G SA注册流程；
3. Registration request、RRCSetupRequest、RRCSetup、RRCSetupComplete、Registration accept/complete等消息解析；
4. NR PDU会话建立流程；
5. MIB、SIB1、RRCReconfiguration解析；
6. 仿真实训系统中的信令分析界面、地图窗口、信令窗口、邻区窗口、无线参数和吞吐率窗口；
7. 5G重选到4G的系统消息配置案例；
8. 随堂测试与任务测评。

客观诊断：

1. 原文专业密度高，但学习路径不够清晰。学生容易看到很多流程图和消息名，却不知道先看什么、每一步说明什么、异常时该看哪里。
2. 原文适合做“流程基础 + 关键字段识读 + 工具证据定位 + 小案例连接复盘”的节点链，不适合拆成每个字段一个节点。
3. P6-T1应补齐P6-T2的前置基础，尤其是注册流程、PDU会话、系统消息、RRC重配和工具界面证据入口。
4. 25张原图多数需要重绘、标注或替换。不能因为出现在教材中就默认可作为数字教材正式媒体。

## 3. 本轮补拆边界

### 3.1 纳入范围

本轮纳入P6-T1中能够支撑学习闭环的内容：

1. 4G/5G信令关键差异；
2. 5G SA注册流程和关键注册消息；
3. PDU会话建立流程；
4. MIB/SIB1系统消息；
5. RRCReconfiguration的典型使用场景；
6. 信令分析工具中的地图、信令、邻区、无线参数和吞吐率证据入口；
7. 5G重选到4G案例中的系统消息和优先级判断。

### 3.2 暂不纳入范围

以下内容不在本轮直接展开：

1. 不按3GPP协议逐字段穷尽解释；
2. 不把每一条信令消息、每一个信元单独拆成节点；
3. 不把P6-T1写成完整协议教材；
4. 不直接进入P6-T2的覆盖、接入、切换、掉线复杂问题复盘；
5. 不把原图中的软件界面、地图和信令截图直接作为正式数字教材媒体。

## 5. 关系预案

P6-T1在V0.3.8中已经作为项目六任务骨架存在，并已有若干任务级关系。补拆后需要把任务级关系下沉到详细节点。

### 5.1 内部递进关系

建议内部主链为：

```text
P6T1-N01
-> P6T1-N02
-> P6T1-N03
-> P6T1-N04
-> P6T1-N05
-> P6T1-N06
-> P6T1-N07
-> P6T1-N08
```

该链条不是严格工程执行顺序，而是学生学习顺序：先理解差异和任务，再看注册/PDU/系统消息/RRC重配，最后到工具证据和案例。

## 8. 专业风险与门禁

本轮P6-T1预计风险级别高于普通流程任务，低于P6-T2复杂问题复盘，但仍不能低估。

| 风险 | 表现 | 门禁要求 |
| --- | --- | --- |
| 协议解释风险 | SUCI、5G-GUTI、GUAMI、NSSAI、SSC mode等概念易被简化错误 | 通信专业教师复核 |
| 流程过度简化 | 注册、PDU会话和RRC重配被写成固定线性流程 | 标注“教学化简化”，保留适用边界 |
| 媒体风险 | 原流程图和软件截图不能直接作为正式数字教材资源 | 媒体审查、重绘或标注 |
| 工具依赖风险 | 仿真实训系统界面可能非通用 | 学生端说明“看证据入口”，不写成通用软件操作标准 |
| 案例真实性风险 | 5G重选到4G案例来自教材/仿真材料，真实性和普适性未核验 | 标注教学案例，待专业复核 |
| 学生可懂性风险 | 专业名词密集，容易回到大纲式或协议堆叠 | 后续正文必须按“问题引入-流程解释-字段识读-证据练习-小结”写成教材正文 |

发布、平台、教学和专业复核门禁均应保持 `not_ready` 或等价状态，直到后续复核完成。
