# 课程能力图谱V2优化方案

生成日期：2026-06-23  
对应样本：`samples/course_capability_graph_v2_optimized/index.html`  
上一版：`samples/course_capability_graph_full_review/`

## 1. 优化目标

V1评审版证明了全书6个项目、18个任务和P4-T2深节点可以被可视化串联，但仍偏“教材项目目录映射”。V2的目标是把课程能力图谱从目录映射升级为数字教材的中枢模型。

V2必须满足以下要求：

1. 以课程标准、岗位任务和职业能力为上层依据；
2. 主链体现岗位工作过程，不直接复制项目目录；
3. 项目和任务作为能力节点的承载场景，而不是图谱主骨架；
4. 每个能力节点都能挂接资源、学习活动、评价方式和审核状态；
5. P4-T2继续作为深展开样板，P2-T3作为第一个非P4-T2迁移试拆样本，其余任务先做一级能力映射；
6. 图谱能支撑后续卡片、动画、互动、小游戏、学习单、教师讲评和平台输出。

## 2. V1主要问题

| 问题 | 表现 | V2处理 |
| --- | --- | --- |
| 主链偏目录 | CG-01到CG-07基本对应项目一到项目六 | 改成岗位工作过程链 |
| 标准依据缺失 | 没有显式挂接课程标准、岗位任务、数字教材标准 | 增加依据层 |
| 资源评价不足 | 有活动和产出，但缺少资源、评价、审核状态字段 | 每个能力节点补齐资源、活动、评价、审核 |
| 任务粒度不均 | V1只有P4-T2有深节点，其他任务只是标题 | V2先保留P4-T2深样章，再补P2-T3迁移试拆，后续逐步扩展 |
| 信令分析位置不清 | 被放在最后一个线性项目 | 改为高阶诊断与复盘支撑能力 |

## 3. V2图谱层级

V2采用五层结构：

1. **依据层**：专业教学标准、国家职业技能标准、数字教材标准、职业教育关键要素改革要求；
2. **岗位工作过程层**：从需求采集到测试、分析、方案、实施、验证、复盘的工作流程；
3. **能力单元层**：可学习、可训练、可评价的能力单元；
4. **项目任务层**：教材6个项目、18个任务在能力图谱中的位置；
5. **资源评价层**：卡片、表图、动画/互动/小游戏、学习单、教师材料、评价方式和审核状态。

## 4. V2岗位工作过程主链

V2不再以项目名称作为主链，而采用以下7个岗位工作过程节点：

| 节点 | 名称 | 含义 |
| --- | --- | --- |
| JP-01 | 明确场景与需求 | 收集站点、场景、投诉和业务需求，判断要解决什么问题 |
| JP-02 | 组织测试与采集数据 | 设计并执行DT/CQT、业务体验和必要的专项测试 |
| JP-03 | 整理数据与识读指标 | 处理测试、监控、参数和日志材料，形成可判断的数据基础 |
| JP-04 | 定位问题与制定方案 | 识别覆盖、干扰、切换、容量、体验等问题，并形成优化方案 |
| JP-05 | 实施优化与记录变更 | 执行参数、工程、容量或策略优化，并记录实施依据 |
| JP-06 | 验证效果与表达结论 | 复测优化效果，形成判断、依据、边界和报告表达 |
| JP-07 | 持续提升与复杂复盘 | 对未闭环问题做性能提升、信令分析和复杂问题复盘 |

## 6. P4-T2深展开样板

P4-T2仍保留8个详细节点，但V2中把它们挂接到AU-07/AU-08，而不是孤立存在：

1. 识别验证场景；
2. 区分改善与达标；
3. 读覆盖指标；
4. 读移动性指标；
5. 读体验与容量指标；
6. 选择判断依据；
7. 形成验收结论；
8. 修正职业表达。

这8个节点满足“学习动作 + 资源 + 评价产出”的要求，可作为其他任务后续深拆模板。

## 7. P2-T3迁移试拆

用户认可V2方向后，已选择 `P2-T3 5G网络测试数据分析` 作为第一个非P4-T2任务试拆对象。选择P2-T3的原因是：它位于 `JP-03 整理数据与识读指标` 和 `AU-03 测试问题处理与数据分析`，不是P4-T2的相邻报告任务，更能检验V2图谱能否跨项目迁移。

P2-T3已试拆出8个详细能力节点：

1. 明确分析任务与数据来源；
2. 完成LOG导入与报告导出；
3. 识读关键指标与判断边界；
4. 判断覆盖类异常；
5. 判断移动性/邻区异常；
6. 归纳问题类型与原因链；
7. 制定整改建议；
8. 输出分析报告并连接复测。

该试拆说明V2不只是能描述P4-T2，还能把一个传统教材任务转化为“资源、活动、评价、审核”的节点结构。对应文件为：

1. `reports/P2-T3详细能力节点试拆报告.md`
2. `reports/P2-T3详细能力节点映射表.csv`
3. `samples/course_capability_graph_v2_optimized/`

## 8. 当前仍不满足的部分

V2仍是评审优化版，不是最终正式图谱：

1. 除P4-T2和P2-T3外，其他16个任务尚未完全拆到详细能力节点粒度；
2. 标准依据目前是摘要级挂接，未逐条绑定标准原文条款；
3. 专业阈值、案例数据和结论口径仍需通信专业教师复核；
4. 资源卡片、互动、动画、小游戏仍有部分是转化位；
5. 使用数据事件、补救学习路径和版本更新机制还未完整建模。

## 9. 下一步建议

先评审V2与P2-T3试拆是否解决“目录映射”问题。

如果V2方向成立，下一步应做两件事：

1. 建立课程能力图谱正式字段规范；
2. 选择第二个非P4-T2任务试拆到详细能力节点，建议优先考虑 `P4-T3 优化报告输出` 或 `P5-T3 全网性能提升验证`，分别验证职业表达链和持续复盘链。
