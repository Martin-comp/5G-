# 项目四任务2：能力图谱样本

状态：AI 初提，需通信专业专家与编辑复核。

## 1. 主能力链

测试/仿真结果读取 -> 指标解释 -> 问题类型判断 -> 参数/工程因素核查 -> 优化前后对比 -> 结论与报告输出

## 2. 能力节点

- CAP-COVERAGE：验证覆盖优化结果
- CAP-HO：验证切换优化结果
- CAP-LATENCY：验证时延优化结果
- CAP-RATE：验证速率优化结果
- CAP-CAPACITY：验证容量优化结果
- CAP-DROP：验证掉线优化结果
- CAP-EVIDENCE：形成优化证据链与报告

## 3. 资源与评价绑定

| 资源/评价 | 支撑能力 | 说明 |
| --- | --- | --- |
| 覆盖评估指标表 | 验证覆盖优化结果 | 需核对运营商阈值来源与适用范围 |
| SA/NSA切换流程图组 | 验证切换优化结果 | 需补充流程步骤解释和信令证据 |
| 仿真软件验证步骤截图组 | 形成优化证据链与报告 | 需补充软件版本、初始参数、修改参数、输出数据 |
| 任务测评实践题 | 形成优化证据链与报告 | 应改造为可评分任务单 |
