# 整书预览版全平台导航体系优化实施计划 V0.1

生成时间：2026-06-27

## 目标

修正 `samples/digital_textbook_overall_prototype_overall_0_5_clean_preview/` 中一级导航、二级导航和右侧上下文混用的问题，使整书预览版在课程、项目、图谱、教师、资源、交付和任务页之间形成统一、可理解的引导体系。

## 问题判断

当前整书预览版把顶部一级菜单和左侧 P1-P6 项目目录长期并置，导致用户无法判断：

1. 顶部菜单和左侧菜单是否同级；
2. 左侧项目目录是否对图谱、教师、资源、交付等所有页面都有效；
3. 右侧学习上下文到底跟随当前页面、当前项目还是当前图谱节点；
4. 从整书进入项目、从项目进入任务、从任务回到图谱的路径是否一致。

该问题属于全平台信息架构问题，不属于首页局部样式问题。

## 统一规则

1. 一级导航回答“我现在在哪个使用场景”：
   - 课程
   - 项目
   - 图谱
   - 教师
   - 资源
   - 交付
2. 二级导航回答“当前场景下我要选择什么对象”：
   - 课程页不显示项目目录；
   - 项目页显示 P1-P6 项目目录；
   - 图谱页显示图谱主链和重点项目节点导航；
   - 教师页显示教师工作流；
   - 资源页显示资源筛选；
   - 交付页显示交付路径。
3. 右侧上下文只绑定当前页面和当前选中对象，不允许出现左侧选中项目和右侧节点不一致的状态。
4. 任务页中的“学生学习、教师带教、任务资源”属于任务内视图，不能与整书一级导航混淆。

## 修改范围

### 1. 整书入口 `index.html`

修改固定左栏结构，增加可动态变更的 `leftRail` 标识。左栏仍由同一容器承载，但不同一级视图渲染不同内容。

### 2. 整书入口 `app.js`

新增或改造：

1. `renderLeftRail()`：按 `state.view` 渲染不同二级导航；
2. `renderContextPanel()`：按 `state.view` 渲染当前视图上下文；
3. `setView()`：切换一级视图时只改变使用场景，不无条件污染项目或图谱状态；
4. `setProject()`：只在进入项目学习场景时使用；
5. `renderResources()`：加入资源筛选状态；
6. `renderPublish()`：加入交付路径状态；
7. `renderTeacher()`：加入教师工作流状态。

### 3. 整书入口 `styles.css`

调整：

1. 首页和非项目视图不再呈现 P1-P6 项目目录；
2. 左侧栏标题、说明、按钮样式兼容项目、图谱、教师、资源和交付；
3. 不同视图的二级导航具备明确的视觉身份；
4. 移动端保持可读。

### 4. P4-T2任务页

调整任务页顶部文案：

1. 明确“学生学习、教师带教、任务资源”是任务内视图；
2. “返回整书预览”保持返回整书入口；
3. “课程能力图谱”按钮改为“本任务图谱”，避免误认为完整图谱页。

## 验证要求

1. 顶部六个一级视图均可点击切换；
2. 课程页不显示 P1-P6 左侧项目目录；
3. 项目页显示 P1-P6 项目目录；
4. 图谱页左侧显示图谱导航；
5. 教师页左侧显示教师工作流；
6. 资源页左侧显示资源筛选并能影响资源表；
7. 交付页左侧显示交付路径；
8. 右侧上下文与当前视图一致；
9. 从整书入口可以打开 P4-T2任务页；
10. P4-T2任务页的任务内视图切换可用；
11. 控制台无错误。

## 不做事项

1. 不改治理评审版 `overall-0.5`；
2. 不改课程能力图谱 V2.1 单独评审版的关系呈现；
3. 不新增第二个深样章；
4. 不把阶段性研发状态重新暴露到 clean preview。
