## 5. 关系逻辑复核

P4-T1内部主线成立：

```text
P4T1-N01 -> P4T1-N02 -> P4T1-N03 -> P4T1-N04 -> P4T1-N05 -> P4T1-N06
```

跨任务关系成立：

1. `P2T3-N07 -> P4T1-N01/N02`：整改建议支撑优化对象和动作类型判断；
2. `P3T3-N06 -> P4T1-N01/N03`：参数异常清单支撑实施边界和参数依据读取；
3. `P4T1-N03 -> P3T3-N06`：参数依据不足时回流到参数异常分析；
4. `P4T1-N05 -> P4T2-N01`：实施变更记录支撑验证场景识别；
5. `P4T1-N06 -> P4T2-N01`：复测验证交接清单进入P4-T2。

复核判断：关系逻辑通过。

需要保留的观察项是P4-T3报告输出关系。当前不提前追加P4T1-N05到P4-T3的关系，因为P4-T3尚未细拆，提前追加容易制造低质量跨任务关系。后续若P4-T3进入增量验证，应专门检查P4-T1变更记录、P4-T2验证结论和P4-T3报告输出之间的关系。
