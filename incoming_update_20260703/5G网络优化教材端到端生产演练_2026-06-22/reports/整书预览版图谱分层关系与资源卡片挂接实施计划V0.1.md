# 整书预览版图谱分层关系与资源卡片挂接实施计划 V0.1

生成时间：2026-06-27

## 目标

在 `samples/digital_textbook_overall_prototype_overall_0_5_clean_preview/` 中试做B方案：把当前“节点清单式图谱页”改造为“课程主链 -> 项目/任务 -> 能力节点 -> 资源卡片/评价产出”的分层关系图，并实现图谱节点与资源卡片的双向定位。

## 背景问题

当前clean preview图谱页存在两个问题：

1. 页面看起来更像节点清单和导航面板，不像图谱；
2. 资源虽然在 `data.js` 中有 `node` 字段，但前端没有实现“节点 -> 资源卡片 -> 学习活动/评价”的可点击关系。

这违反了既有原则：课程能力图谱应连接课程标准、岗位任务、项目任务、能力节点、卡片资源、学习活动和评价方式；节点与卡片可以是一对一、一对多、多对一或多对多，但必须可追踪。

## 改造范围

### 修改文件

1. `samples/digital_textbook_overall_prototype_overall_0_5_clean_preview/app.js`
   - 增加资源挂接解析函数；
   - 改造 `renderGraph()` 为分层关系图；
   - 增加节点点击、资源卡片点击和互相高亮逻辑；
   - 改造图谱页右侧上下文，加入关联资源和评价产出。
2. `samples/digital_textbook_overall_prototype_overall_0_5_clean_preview/styles.css`
   - 增加分层图谱、连线、资源卡片、活动/评价区样式；
   - 保持桌面端和移动端可读。
3. `samples/digital_textbook_overall_prototype_overall_0_5_clean_preview/qa/run_graph_resource_qa.cjs`
   - 新增真实点击QA，验证图谱视觉结构、节点资源挂接、资源反向定位和控制台错误。

## 不改范围

1. 不改治理评审版 `overall-0.5`；
2. 不改V2.1关系评审版；
3. 不重建课程能力图谱主数据；
4. 不新增P2-T3深样章；
5. 不把当前资源卡片写成专业复核完成或正式出版资源。

## 设计规则

1. 图谱页首屏必须有明显分层结构，而不是单纯按钮清单；
2. 至少展示四层：课程主链、重点项目路径、能力节点、资源与评价；
3. 点击能力节点后，必须显示关联资源卡片；
4. 点击资源卡片后，必须反向高亮所属能力节点；
5. 无资源挂接的节点必须显示“暂无直接资源卡片”，不能伪造资源；
6. 资源卡片必须说明资源类型、所属项目/任务、用于哪个学习动作、形成什么产出；
7. 图谱页仍是正式预览层，不能暴露研发过程语言。

## 验证要求

1. `node --check app.js` 通过；
2. `node --check qa/run_graph_resource_qa.cjs` 通过；
3. 浏览器QA真实点击通过；
4. QA至少验证：
   - 图谱页出现分层关系图；
   - 存在课程主链、重点项目路径、能力节点和资源卡片层；
   - 点击 `P2T3-N03` 后能看到“关键指标读法与边界表”资源卡片；
   - 点击 `P4T2-N01` 或P4-T2相关节点后能看到P4-T2学习任务页资源卡片；
   - 点击资源卡片能反向高亮节点；
   - 控制台无错误。

## 预期结论口径

如果通过，只能说明clean preview中“图谱表达和资源挂接的前端样式”阶段性走通；不代表完整课程能力图谱专业复核完成，不代表所有资源已制作完成，也不代表出版社平台接口已完成。
