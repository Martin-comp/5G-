# 样章3.5A-1教师试看说明

生成日期：2026-06-23  
适用样章：`samples/task_workbench_3_5a1_two_period_sample/`  
试看对象：通信类或5G网优相关课程一线教师

## 1. 试看目的

本次试看不是验证页面是否好看，而是验证该样章能否支撑教师用2课时组织一次“5G网络优化结果验证”学习任务。

重点观察：

1. 学生是否知道第一步做什么；
2. 学生是否能从投诉语言转向要看的数据；
3. 学生是否能区分改善和达标；
4. 学生是否能写出自己的修正句；
5. 学生最终结论是否包含判断、依据、边界和建议；
6. 教师是否能按2课时组织课堂和讲评。

## 2. 建议课堂安排

本任务暂定2课时，共90分钟。

| 时间 | 教师动作 | 学生产出 |
| --- | --- | --- |
| 第1课时0-8分钟 | 投屏首屏学习入口，确认学生知道最终提交物 | 能说出最终要交验收结论和修正句 |
| 第1课时8-25分钟 | 完成入门样例和对照样例A，追问为什么覆盖不是全部 | 投诉归类、验证流程、前两条修正句 |
| 第1课时25-45分钟 | 完成对照样例B，板书平均值、95分位和容量边界 | 指标标注和一条边界表达 |
| 第2课时45-63分钟 | 完成半扶手练习，组织依据分类 | 通过依据、边界和背景分类 |
| 第2课时63-82分钟 | 完成独立实践，要求学生提交结论 | 四段式验收结论 |
| 第2课时82-90分钟 | 用修正句和模拟学情讲评 | 明确待改进表达和专业疑点 |

## 3. 试看记录重点

教师试看时建议记录：

1. 哪一步学生最慢；
2. 哪个术语最容易卡住；
3. 哪类错误最多；
4. 学生是否真的写了修正句；
5. 学生是否只是照抄参考表达；
6. 2课时时间是否足够；
7. 哪个案例数据或阈值需要专业复核；
8. 哪个资源最值得优先做成动画、互动或小游戏。

## 4. 不应误解

1. 本版案例为教学模拟案例，不是真实工程项目；
2. 阈值为本课目标，不代表行业通用标准；
3. 模拟学情不是真实学生数据；
4. 学生修正句只保存在浏览器本地状态，不是正式学习记录；
5. 术语字典是配置化词条，不是真实AI助手。
