## 1. 评审结论

样章3.5A相对3.5有实质进步，已经基本完成“评审准备版”的目标：学生首屏入口、每例完成标准、术语字典、二次修正提示、学生化课程能力图谱、教师课堂组织工具和模拟学情看板均已进入页面，并通过桌面端和移动端浏览器QA。

但3.5A仍不能判定为“课堂可直接使用版”或“出版社正式展示版”。当前最主要的问题不是缺少栏目，而是部分栏目仍停留在“可看见”，尚未完全达到“可教学、可自学、可收集真实学习产出、可专业复核”的程度。

内部预评分：82/100。

门禁判断：

1. 通过内部评审准备门禁；
2. 有条件进入小范围一线教师/学生试看；
3. 不建议直接进入出版社正式展示；
4. 不建议直接拆解为工具链模块；
5. 建议先做3.5A-1小修，再组织真实试看。

## 3. 已解决的问题

### 3.1 学生首屏入口明显增强

3.5A首屏已经回答了四个关键问题：

1. 第一步做什么；
2. 本节要形成什么产出；
3. 做到什么程度算完成；
4. 最终提交什么。

这解决了3.5中“学生首次进入不知道从哪里开始”的主要问题。

### 3.2 每例完成标准已经进入主学习区

五个案例均有完成标准，并且完成标准与案例教学功能基本一致：

1. 入门样例：投诉线索归类；
2. 对照样例A：移动性验证流程；
3. 对照样例B：平均值与尾部体验区分；
4. 半扶手练习：依据、边界、背景分类；
5. 独立实践：判断、依据、边界、建议四段式结论。

这个结构比3.4和3.5更接近一节课的递进学习逻辑。

### 3.3 课程能力图谱不再只是装饰

当前图谱至少已经承担三件事：

1. 说明能力节点的前置和后续关系；
2. 把节点映射到案例、卡片、学习活动和评价方式；
3. 支持从图谱节点定位到关联学习任务。

这基本符合“课程能力图谱作为暗线骨架”的阶段性要求。

### 3.4 教师页有实质增强

教师页已包含：

1. 45分钟课时安排；
2. 投屏和板书建议；
3. 关键提问脚本；
4. 小组分工；
5. 典型答案；
6. 模拟学情看板；
7. 课堂控节奏说明；
8. 自学布置与验收；
9. 专业复核清单。

这已经不是单纯答案页，开始接近课堂组织工具。

### 3.5 边界声明比较清楚

样章明确标注：

1. 案例为教学模拟案例；
2. 阈值为本课目标，不代表通用行业标准；
3. 术语字典不是AI助手；
4. 模拟学情不是真实学生数据；
5. 正式发布前需专业教师复核。

这些边界有助于避免把试验样章误当作正式教材。

## 4. 主要问题

### P0-1 课时节奏存在明显冲突

样章学生端学习流程写为：

1. 识别问题 5分钟；
2. 建立路径 12分钟；
3. 纠正常见误区 18分钟；
4. 半独立处理 15分钟；
5. 形成结论 20分钟。

合计为70分钟。

但教师页标题和课时安排写的是45分钟课堂组织。这是当前最明确的内部矛盾。若拿给一线教师评审，教师会直接质疑：到底是一节45分钟课，还是一个70分钟学习任务包。

处理建议：

1. 明确3.5A是一课时、两课时，还是“课堂45分钟 + 课后自学30分钟”；
2. 如果坚持45分钟课堂，应把学生端流程时间同步改为45分钟；
3. 如果保留70分钟，应把教师页改为“课堂45分钟 + 课后25分钟自学任务”。

### P0-2 二次修正还不是真正的学习闭环

3.5A反馈后出现了“再试一次”和“形成更好结论”，但目前主要是按钮和提示，并没有真正要求学生形成一个修改后的答案。

问题在于：

1. 学生可以看到参考结论，但不一定会修改自己的表达；
2. “形成更好结论”更像跳到参考答案，不是修订过程；
3. 除最后一个结论拼装活动外，其他案例缺少学生自己的可保存表达；
4. 教师页的模拟学情无法对应真实学生提交内容。

处理建议：

1. 每例增加一个“我的修正句”或“我现在的判断”输入区；
2. 反馈后要求学生至少改写一句依据或边界；
3. 学习单应优先显示学生修正结果，再显示参考结论；
4. 教师页的典型误区应能关联到学生修正前后的样例。

### P0-3 学习单目前像参考答案，不像学生提交物

当前“本例学习单”结构清晰，但内容直接取自标准结论。这样做适合展示目标答案，不适合证明学生完成了学习。

风险：

1. 学生可能跳过思考，直接看结构化答案；
2. 教师无法判断学生真实卡在哪里；
3. 如果后续做学习数据回收，当前学习单字段不足以承载真实学习证据。

处理建议：

1. 将学习单拆成“我的填写”和“参考表达”两层；
2. 未完成活动前只显示填写框，不直接显示完整参考结论；
3. 完成后允许学生对照修改，并保存修改历史。

### P1-1 自学模式比3.5清楚，但仍偏提示型

自学模式已经有术语小卡和提交前自查，但对基础弱学生来说仍可能不够。

问题在于：

1. 错误原因解释还较短；
2. 没有分层提示，例如“先看场景词、再看指标组、最后写边界”；
3. 不同错误类型没有不同补救路径；
4. 自学学习单和课堂学习单没有明显差异。

处理建议：

1. 每类活动增加“卡住时先看哪里”；
2. 对常见错误增加反例解释；
3. 自学模式下优先显示“提示1/提示2/示范一句”，课堂模式下由教师控制显隐。

### P1-2 学生端仍有少量后台化表达

3.5A已经把很多“节点、证据、映射”改成教学语言，但图谱弹层、资源转化页和部分按钮仍会出现：

1. `P4T2-N01` 这类编号；
2. “节点详情”；
3. “关联卡片”；
4. “资源转化”；
5. “评价方式”。

这些表达不一定错误，但对学生来说仍偏后台。若后续面向学生发布，应进一步区分：

1. 学生可见：我正在练什么、我需要完成什么；
2. 教师可见：能力点、教学目标、评价标准；
3. 编辑/平台可见：节点编号、资源映射、封装字段。

### P1-3 教师页还缺少可直接带进课堂的材料形态

教师页现在信息比较完整，但仍偏页面说明，还不是完整课堂工具包。

缺少：

1. 一页式教师授课单；
2. 学生任务单；
3. 投屏版简洁视图；
4. 课堂观察记录表；
5. 小组汇报模板；
6. 课后自学提交要求。

如果要真实试看，至少需要补一份“教师试看说明”和“学生观察记录表”，否则一线教师可能不知道评审重点是什么。

### P1-4 专业复核仍停留在清单层

3.5A已经提醒需要专业复核，但还没有形成可执行复核包。

当前风险：

1. 3GPP来源只能支撑指标方向，不能直接证明样章阈值合理；
2. 教学模拟案例的数据是否符合通信专业教学逻辑仍需专家判断；
3. 各案例结论口径是否准确，还缺逐项复核记录；
4. 原教材非通用仿真截图的替换/重绘策略仍未进入本版。

处理建议：

1. 导出“案例-指标-阈值-结论-复核问题”表；
2. 给每个阈值标注来源类型：本课目标、标准方向、原教材、AI教学模拟、待专家复核；
3. 真实试看前至少完成一次通信专业教师快速复核。

## 6. 建议的下一步

建议不要直接进入工具链拆解。当前更合理的下一步是做一个轻量的3.5A-1修订包，范围控制在评审前必要修正：

1. 统一45分钟/70分钟课时逻辑；
2. 增加每例“我的修正句”或“我的判断”输入区；
3. 将学习单改为“学生填写 + 参考表达”双层；
4. 进一步学生化图谱弹层，把编号和节点语言降到后台或教师层；
5. 生成一份教师试看说明和学生观察记录表；
6. 生成专业复核表，列出案例、指标、阈值、结论和待复核点。

完成3.5A-1后，再组织小范围真实试看。真实试看应至少记录：

1. 学生是否知道第一步做什么；
2. 每例完成时间；
3. 哪些术语最卡；
4. 哪类错误最多；
5. 学生是否能独立写出判断、依据、边界和建议；
6. 教师是否能按45分钟组织课堂；
7. 通信专业教师是否认可案例数据、阈值和结论口径。
