## 1. 修订原因

P3-T3 V0.3.1增量已经通过结构校验，但内部评审判定不应直接合并V0.3.2。主要原因有三项：

1. 无线侧、传输侧、核心网侧参数检查在V0.3.1中被写成线性顺序，容易误导为固定操作流程；
2. 验证报告写“资源活动评价挂接共19条”，但CSV实际为20条；
3. A3事件未触发切换案例涉及的 `image178`、`image179` 没有独立进入媒体审查挂接。

V0.3.1A只解决上述合并前必要问题，不扩展学生端页面，不生成教师材料，不进入工具链拆解。

## 4. 关系表修订

V0.3.1关系表共24条。V0.3.1A关系表调整为26条。

核心修订是把原来的线性关系：

```text
P3T3-N02 -> P3T3-N03 -> P3T3-N04 -> P3T3-N05 -> P3T3-N06
```

改为并列分支和结果汇聚：

```text
P3T3-N01 -> P3T3-N02
P3T3-N02 -> P3T3-N03
P3T3-N02 -> P3T3-N04
P3T3-N02 -> P3T3-N05
P3T3-N03 -> P3T3-N06
P3T3-N04 -> P3T3-N06
P3T3-N05 -> P3T3-N06
```

这样能表达真实学习和工作逻辑：学生先明确问题场景，再理解参数口径，然后根据场景选择无线、传输、核心网检查对象，最后把检查结果汇总为参数异常清单。
