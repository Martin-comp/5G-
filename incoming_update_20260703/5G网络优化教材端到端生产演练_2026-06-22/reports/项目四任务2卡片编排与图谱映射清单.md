# 项目四任务2卡片编排与图谱映射清单

生成日期：2026-06-22  
样章对象：项目四 / 任务2：5G网络优化结果验证  
依据文件：`卡片化资源单元与能力图谱映射规范.md`

## 0. 编排目标

本清单把“5G网络优化结果验证”样章拆解为可教学、可追踪、可编辑的卡片序列。拆解原则是：

1. 每张卡必须承载一个完整学习动作；
2. 卡片与能力图谱节点建立映射；
3. 单元整体形成“情境 -> 判断 -> 知识 -> 证据 -> 任务 -> 反馈 -> 教师讲评”的闭环；
4. 页面呈现可以灵活美观，但资源层必须保持结构化。

## 3. 单卡内容完整性要求

### P4T2-C01 情境卡：视频卡顿是不是优化没做好？

完整内容应包含：

- 场景：某校园区域完成 5G 网络优化后，普通网页访问恢复正常，但晚间直播上行仍有明显延迟，视频通话偶发卡顿；
- 角色：学生以网络优化助理工程师身份参与结果验证；
- 任务：判断本次优化是否达标，并说明还需要查看哪些证据；
- 输出：一句初步判断，不能直接给最终结论。

### P4T2-C02 诊断交互卡：问题可能属于哪一类？

完整内容应包含：

- 选项：覆盖问题、切换问题、端到端性能问题、掉线或业务保持问题、证据不足；
- 反馈：选择每类问题后提示需要查看的证据；
- 记录：保留学生初次选择和修改后的选择；
- 目的：训练“先分类，再找证据”的网优思维。

### P4T2-C03 知识卡：覆盖验证看什么

完整内容应包含：

- 解释 SS-RSRP 与 SS-SINR 在覆盖验证中的作用；
- 说明弱覆盖、越区覆盖、交叉覆盖的判断思路；
- 给出“覆盖改善不等于业务体验一定改善”的提示；
- 连接到 P4T2-C04 覆盖证据判断。

### P4T2-C04 证据卡：优化前后覆盖指标对比

完整内容应包含：

- 一张优化前后覆盖指标对比表；
- 指标变化说明；
- 学生标注哪些指标支持“覆盖改善”；
- 学生判断证据是否足以推出“整体优化达标”。

### P4T2-C05 知识卡：切换验证看什么

完整内容应包含：

- A1/A2/A3/A4/A5/A6、B1/B2 事件的教学化解释；
- SA/NSA 切换验证的基本流程；
- 说明切换异常可能导致业务卡顿或中断；
- 明确本卡不展开完整协议细节。

### P4T2-C06 交互卡：切换流程是否合理？

完整内容应包含：

- 切换验证流程的若干步骤；
- 学生排序或选择异常点；
- 即时反馈：错在事件理解、流程顺序，还是证据不足；
- 记录学生排序结果，供教师讲评。

### P4T2-C07 知识卡：端到端性能验证看什么

完整内容应包含：

- 解释时延、速率、容量、掉线率与业务体验的关系；
- 区分“覆盖指标改善”和“端到端业务体验改善”；
- 给出视频通话、直播上行场景下优先关注的指标；
- 连接到 P4T2-C08 性能证据卡。

### P4T2-C08 证据卡：业务体验与性能指标对照

完整内容应包含：

- 一组优化前后业务性能指标；
- 学生判断哪些指标支持“直播上行延迟仍未解决”；
- 学生选择还需要补充的数据；
- 提醒不能只用单一指标下结论。

### P4T2-C09 证据卡：仿真截图能说明什么

完整内容应包含：

- 教材中仿真软件截图或可替代的重绘示意；
- 截图可支持的判断；
- 截图不能单独支持的判断；
- 学生选择截图在证据链中的位置。

### P4T2-C10 任务卡：写出优化结果验证结论

完整内容应包含结构化任务单：

| 字段 | 要求 |
| --- | --- |
| 问题类型判断 | 覆盖、切换、性能、证据不足，可多选 |
| 核心证据 | 至少选择 2 条证据 |
| 优化前后变化 | 填写关键指标变化 |
| 是否达标 | 达标、部分达标、未达标、无法判断 |
| 判断理由 | 80-150 字 |
| 后续建议 | 1-2 条 |

### P4T2-C11 反馈卡：你的证据链完整吗？

完整内容应包含：

- 参考分析框架，不给唯一标准答案；
- 常见误区：只看覆盖、不看业务；只看截图、不看指标；把局部改善等同于整体达标；
- 自查问题：我的结论有没有证据？有没有说明证据边界？
- 允许学生修改结论。

### P4T2-C12 教师卡：课堂讲评与学情观察

完整内容应包含：

- 教学目标和建议时长；
- 模拟学情：完成率、错误类型分布、证据缺失分布；
- 讲评顺序建议；
- 教师可调整项：跳过扩展卡、开启/关闭测评、导出任务单；
- 明确标注“样章阶段学情数据为模拟数据”。

## 5. 对页面制作的约束

1. 首屏必须出现 P4T2-C01 的真实任务，不得只出现大标题；
2. 每张卡必须能展开完整内容，不得只显示一句话摘要；
3. 卡片之间必须有“下一步为什么看这张卡”的连接提示；
4. 交互卡必须记录学习数据；
5. 证据卡必须说明证据边界；
6. 教师卡必须标注模拟数据；
7. 页面可以采用横向时间线、任务地图、卡片栈等呈现方式，但资源层仍以卡片清单管理。
