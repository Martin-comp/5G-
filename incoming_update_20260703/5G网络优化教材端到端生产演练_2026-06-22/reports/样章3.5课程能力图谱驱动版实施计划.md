# 样章3.5课程能力图谱驱动版实施计划

生成日期：2026-06-23

## 1. 目标

在样章3.4“多案例递进式课堂任务版”的基础上，新建样章3.5，重点解决两个问题：

1. 练习方式有目的地多样化，减少单纯问答和选择题；
2. 将“能力地图”升级为“课程能力图谱”，使其成为数字教材的暗线组织骨架，而不是局部案例导航。

## 2. 不变边界

1. 不覆盖样章3.4，保留其作为上一阶段基线；
2. 不使用1+X作为依据；
3. 案例仍明确标注为教学模拟案例；
4. 专业阈值和结论口径仍需通信专业教师或行业专家复核；
5. 首屏仍以学习任务为主，不把完整课程能力图谱作为第一屏主界面。

## 3. 3.5新增能力

### 3.1 课程能力图谱

新增课程能力图谱弹层，至少包含两层：

1. 全课程工作过程主链：信息采集、网络测试、信息管理、优化实施、结果验证、性能提升、信令分析；
2. 项目四任务2详细子图谱：识别验证场景、区分问题类型、读覆盖指标、读移动性指标、读体验指标、选择判断依据、形成验收结论、修正职业表达。

每个详细节点至少展示：

- 节点编号和层级；
- 学习目标；
- 前置/后续关系；
- 关联项目、任务、案例、卡片；
- 练习活动；
- 评价方式；
- 完成状态。

### 3.2 练习方式改造

3.5不再让五个案例都围绕“选一个答案”展开，而改为五类学习动作：

| 阶段 | 学习动作 | 价值 |
| --- | --- | --- |
| 入门样例 | 投诉线索归类 | 训练学生把自然语言投诉转成验证对象 |
| 对照样例A | 验证流程排序 | 训练移动性问题的验证路径 |
| 对照样例B | 指标行标注 | 训练学生区分通过依据和边界数据 |
| 半扶手练习 | 依据分类 | 训练从多项数据中选择有效依据、边界和背景 |
| 独立实践 | 结论拼装与提交 | 训练岗位化验收表达 |

### 3.3 课堂模式和自学模式分流

课堂模式应出现：

- 教师节奏；
- 分组角色；
- 课堂停顿点；
- 展示和讲评任务。

自学模式应出现：

- 自学路线；
- 术语解释；
- 分步提示；
- 自查清单；
- 尝试后的反馈。

两种模式不能只更换一段备注文字。

## 4. 文件计划

新建目录：

`samples/task_workbench_3_5_graph_driven_sample/`

文件职责：

- `index.html`：页面入口和课程能力图谱弹层容器；
- `data.js`：课程能力图谱、五个递进案例、练习活动、课堂/自学模式、资源转化和来源边界；
- `app.js`：渲染学生学习、教师带教、资源转化、课程能力图谱详情和五类练习交互；
- `styles.css`：响应式布局、图谱弹层、活动组件和模式差异样式；
- `README.md`：样章定位、入口、QA命令、已知边界；
- `qa/run_playwright_qa.cjs`：浏览器QA脚本。

## 5. 验收标准

3.5至少满足：

1. 页面标题和首屏明确为样章3.5；
2. 学生首屏出现“课程能力图谱”入口，但完整图谱不作为首屏主体；
3. 图谱弹层包含课程主链和项目四任务2详细节点；
4. 点击图谱节点后显示节点详情，而不是只跳转案例；
5. 节点详情可跳转关联学习任务；
6. 五个案例练习形态不同；
7. 课堂模式和自学模式的页面结构明显不同；
8. 练习反馈使用教材化语言，减少“答题正确/错误”的机械表达；
9. 资源转化页说明哪些卡片可转为图、表、动画、互动或小游戏；
10. 桌面端和移动端无横向溢出，控制台无错误。

## 7. 当前风险

1. 本次只能形成项目四任务2的详细子图谱，全书完整课程能力图谱仍需后续批量抽取和专家复核；
2. 当前交互仍是静态前端原型，不等同于出版社平台正式接口；
3. 教学模拟案例的专业口径需通信专业教师复核；
4. 练习多样化应服务学习动作，不能为了“看起来丰富”而堆交互。
