## 1. 计划结论

P1-T1和P1-T2适合作为第十二类普通任务成组增量验证对象。

本轮建议采用“共性链条 + 室内分支 + 室外分支 + 汇总输出”的拆分方式，目标是补齐全书最后两个无详细节点任务。

建议候选结构：

1. P1-T1拆为6个详细能力节点；
2. P1-T2拆为6个详细能力节点；
3. 共用若干关系、资源活动评价和风险治理规则；
4. 不把采集表每一个字段、每一张图片、每一个仿真按钮拆成节点。

当前不得直接进入P1页面生产、正式资源包生产、出版社平台挂接或工具链模块拆解。

P1-T1主要包括室内站址、机房配套、主设备、电源传输、组网方式、采集工具、仿真软件入口和室内信息采集表。

P1-T2主要包括室外塔型、天馈设备、室外地形地貌、人口/环境信息、覆盖场景、工具使用、仿真软件入口和室外信息采集表。

两者共同点是：

1. 都是网络规划和优化前的基础信息采集；
2. 都需要明确采集对象、采集工具、记录要求、照片/位置/表格证据；
3. 都涉及现场安全、信息敏感性和数据完整性；
4. 都不能把表格字段逐项拆成能力节点。

## 4. 关系预案

### 4.1 共性采集链条

```text
明确采集任务
-> 识别采集对象和字段类别
-> 选择工具或识别设备对象
-> 完成采集记录
-> 核查完整性和风险项
-> 输出采集成果包
```

### 4.2 项目一内部关系

1. P1-T1和P1-T2共同支撑P1-T3投诉信息采集中的现场基础信息判断；
2. P1-T1/P1-T2输出的采集成果包可支撑P2-T1测试准备、P3-T1网管入口中的数据采集入口、P4/P5优化任务的基础信息判断；
3. P1-T1和P1-T2之间是并列采集分支，不是严格先后关系。

## 5. 资源活动评价设计

建议资源和活动包括：

1. 室内/室外采集任务情境卡；
2. 室内/室外采集字段分类表；
3. 工具用途与使用边界卡；
4. 塔型和天馈识别教学化图表；
5. 室内/室外信息采集记录表；
6. 数据完整性核查单；
7. 采集成果包模板；
8. 现场安全和敏感信息边界判断活动。

## 6. 风险治理重点

本组任务风险明显高于普通知识任务，原因是它涉及真实站址、经纬度、物业业主、电话号码、设备照片、机房和室外环境图片。

必须治理的风险包括：

1. 个人信息和业主联系方式；
2. 站址、经纬度、机房照片和设备照片的敏感性；
3. 电源测量、登高、室外现场观察等安全边界；
4. 原教材图片的版权、可发布性和清晰度；
5. 仿真软件截图的重绘和教学化标注；
6. 表格字段过多导致学生只抄表、不理解采集用途；
7. 真实采集和教学模拟采集的边界。
