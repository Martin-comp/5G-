# 课程能力图谱V0.3.1主数据评审与第二增量任务建议

生成日期：2026-06-24  
适用范围：《5G网络优化教材（高级）》数字教材端到端生产演练  
评审对象：课程能力图谱主数据V0.3.1  

## 1. 本轮评审结论

V0.3.1可以作为下一轮增量验证的当前主数据基线，但只能判定为“有条件通过”，不能写成专家定稿图谱、全书图谱完成或页面生产就绪。

本轮结论如下：

1. V0.3.1正确吸收了P2-T2 V0.3A四节点修订版；
2. P2-T2旧版六节点增量没有进入V0.3.1主表，处理正确；
3. V0.3.1结构一致性通过校验，能够继续承接第二个普通任务增量验证；
4. V0.3.1仍存在专业复核、媒体审查、学生正文、教师材料和页面呈现未完成问题；
5. 下一步不应进入页面制作或工具链模块拆解，应选择第二个不同类型普通任务继续验证主数据机制。

## 3. 对P2-T2合并质量的判断

P2-T2 V0.3A四节点版比旧版六节点更适合进入主数据。理由是：

1. 四节点结构覆盖了完整职业任务链：异常判断、排查处理、现场协调、闭环记录；
2. GPS、逆变器、软件授权、驱动、存储空间等细节没有继续上升为图谱主节点，而是下沉到资源卡片和学习活动；
3. P2-T2能够连接P2-T1测试执行和P2-T3数据分析，补齐项目二内部任务衔接；
4. AU-03和AU-05挂接基本合理，能够表达“数据采集问题处理”和“现场问题闭环”的能力差异。

仍需保留的风险：

1. P2T2-N02绑定车载逆变器图片，当前仍是高风险媒体审查对象，不能直接进入正式教材；
2. P2-T2的硬件、软件、协调升级等口径尚未经过通信专业教师复核；
3. P2-T2目前只有主数据，没有学生端教材正文、教师讲评材料或可运行页面；
4. 当前主数据中“任务拆分详细节点”关系类型尚未在所有已细化任务中统一使用，后续需要决定是否将项目任务到详细能力节点的直属关系标准化。

上述风险不阻止V0.3.1继续作为增量验证基线，但阻止其被写成最终定稿或可直接生产页面的状态。

## 4. 第二个普通任务候选评估

第二个普通任务应满足四个条件：

1. 尚未被详细试拆；
2. 类型上不同于P2-T2的问题处理类任务；
3. 能检验新的资源、活动、评价和关系挂接方式；
4. 不应过早进入过高专业风险或过大工作量。

候选任务评估如下：

| 候选任务 | 验证价值 | 主要风险 | 判断 |
| --- | --- | --- | --- |
| P3-T3 5G网络参数检查 | 能验证配置管理、参数检查、规划/容量/覆盖参数与后续优化实施之间的图谱关系 | 原教材内容公式和截图较多，需要教学化重组和媒体审查 | 推荐 |
| P5-T1 5G全网性能指标采集 | 能补齐P5-T3前置数据源，验证指标采集类任务 | 内容长，且与已试拆P5-T3距离较近，容易只补同一链条 | 备选 |
| P4-T3 5G网络优化报告输出 | 能验证报告输出、职业表达和成果交付 | 与P4-T2深样章距离太近，验证类型不够独立 | 暂缓 |
| P4-T1 5G网络优化方案实施 | 能验证优化实施类任务 | 天线、无线、承载、核心网参数并行，媒体和专业风险较高 | 暂缓 |
| P3-T2 5G网络运行监控 | 能验证运行监控类任务 | 原文体量过大，表格线索343行，不适合作为第二个轻量增量验证 | 暂缓 |

## 5. 推荐选择P3-T3的理由

建议将 `P3-T3 任务3：5G网络参数检查` 作为第二个普通任务增量验证对象。

客观理由：

1. 它尚未详细试拆，能验证V0.3.1是否能从项目任务占位继续扩展；
2. 它属于参数检查和配置管理类任务，明显不同于P2-T2的问题处理类任务；
3. 它能连接P3信息管理、P4优化方案实施、P4结果验证和P5性能提升，关系价值高；
4. 原教材中包含无线参数、容量计算、覆盖计算、参数导入导出等材料，足够支撑资源活动评价挂接；
5. 它能暴露“公式、参数表、网管截图、专业阈值”如何进入主数据治理的问题，比继续选P5-T1更能检验主数据机制的泛化能力。

不建议此时优先选P5-T1的原因：

1. P5-T1虽然重要，但它与已试拆P5-T3同属性能指标链条，第二轮验证的类型差异不够大；
2. P5-T1原文体量更大，容易把增量验证变成指标名词整理；
3. 当前更需要检验“参数检查类任务”能否进入图谱主数据，而不是继续加强已存在的性能验证链条。

## 6. P3-T3预期拆分方向

如果确认选择P3-T3，建议下一步先试拆为5到6个详细能力节点，不宜一开始按每类参数、每个公式或每张截图拆得过细。

建议的初步节点方向：

1. 明确参数检查任务与问题场景；
2. 获取和导出无线网管配置参数；
3. 识读容量、覆盖和规划相关参数边界；
4. 判断无线参数异常或配置不一致；
5. 检查传输网与核心网配合参数；
6. 形成参数检查结论与优化建议。

具体参数项、公式、截图和模板应下沉为资源卡片、互动表格、参数解释卡、案例练习或媒体审查对象，不宜全部升格为图谱主节点。
