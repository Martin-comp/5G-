## 1. 结论摘要

样章3.5相较3.4有实质进步：它把“能力地图”升级为课程能力图谱，并用图谱节点连接案例、卡片、学习活动和评价方式；五个案例也不再依赖单一选择题，而是改为归类、排序、标注、分类和结论拼装等岗位动作。

但从一线教师和学生实际使用角度看，3.5仍不应直接判定为成熟数字教材样章。当前更准确的结论是：

1. 方向成立，可以进入小范围一线试看；
2. 不建议直接进入工具链模块拆解；
3. 不建议作为出版社正式展示版；
4. 必须先完成通信专业教师复核和3.5A修订；
5. 真实教师/学生评审前，必须明确这是教学模拟案例和静态样章原型。

人工反馈修订后内部预评分：77 / 100。原始预评为76 / 100，因“五个案例学习量较大”降级为非阻塞观察项，上调1分。  
门禁判断：有条件通过“进入一线试看”门禁，未通过“进入工具链拆解”门禁。

## 3. 对一线学生使用的判断

### 3.1 已成立的部分

1. 首屏问题比早期版本清楚，学生能看到“投诉、指标和结论如何连成一次可靠验收”的学习任务。
2. 五个案例形成了入门、对照、对照、半扶手、独立实践的递进结构，不再是一例到底。
3. 每个案例有明确学习动作，例如投诉归类、流程排序、指标标注、依据分类、结论拼装。
4. 学生不只是阅读材料，而是需要产生可检查的中间结果。
5. 自学模式已不只是通用备注，至少提供了术语小卡、步骤提示和提交前自查。

### 3.2 仍存在或需要验证的问题

1. 学生首次进入时，仍可能不知道“我应该先做哪一步、做到什么程度才算完成”。当前有路径，但缺少更明确的第一步操作指令和完成标准。
2. 五个案例数量本身不作为当前问题。本单元单案例体量不大，五例结构可以保留；后续单元可按内容需要在3-5个案例之间规划。真实课堂仍建议记录每例完成时间，用于校准节奏。
3. 互动反馈能说明结果，但反馈后的“再学一遍、改正一次、形成更好答案”的二次学习路径还不够强。
4. 课程能力图谱对学生来说仍偏后台化，学生可能知道它可点，但未必理解它和自己学习任务之间的关系。
5. 专业术语解释仍偏简短，基础较弱学生可能需要更细的低门槛解释和反例。3.5A可在右侧设置术语字典栏目，先使用配置化词条，后续再升级为AI助手。

## 4. 对一线教师使用的判断

### 4.1 已成立的部分

1. 教师页已经从学生学习路径中分离，没有把教师卡混入学生栏目。
2. 教师可以看到课堂流程、小组分工、讲评问题和专业复核风险。
3. 五类学习活动能为教师讲评提供比选择题更丰富的观察点。
4. 课程能力图谱可以帮助教师解释本节课不是孤立案例，而是课程能力链条中的一个节点。

### 4.2 仍存在的问题

1. 教师页目前更像教学提示，不是完整的课堂组织工具。还缺少可直接使用的课时安排、板书/投屏建议、提问脚本和典型答案。
2. 样章没有真实学生提交汇总，因此教师还不能看到错误分布、常见误区统计和讲评优先级。3.5A可以先用明确标注的模拟数据验证栏目结构。
3. 教师若不了解5G网优专业，仍难判断案例数据和阈值是否正确。3.5A可提供专业复核清单、来源边界和待审核标记；不要求非专业教师自行完成专业判断。
4. 课堂模式和自学模式已有结构差异，但教师端尚未说明“课堂模式下教师具体如何控节奏，自学模式下教师如何布置和验收”。

## 7. 真实评审应验证的问题

### 7.1 学生评审问题

建议选取6-10名职业院校相关专业学生，其中至少包含基础较弱学生。

评审任务：

1. 不讲解页面，观察学生能否在1分钟内说出本节要做什么；
2. 让学生独立完成第一个入门样例，记录是否卡在术语、数据表、按钮还是任务理解；
3. 让学生完成一个对照样例，观察是否能说出“覆盖达标不等于全部验收通过”；
4. 让学生完成独立实践，检查结论是否包含判断、依据、边界和建议；
5. 询问学生是否理解课程能力图谱对自己学习有什么帮助。

必须记录：

1. 首次理解时间；
2. 完成每个案例的时间；
3. 哪一步需要教师解释；
4. 哪些词看不懂；
5. 哪个互动真正帮助了理解；
6. 独立实践结论是否可讲评。

### 7.2 教师评审问题

建议选取2-3名通信类课程一线教师。

评审任务：

1. 判断5个案例是否符合5G网优结果验证的教学逻辑；
2. 判断指标、阈值和结论口径是否专业上可接受；
3. 判断课堂模式是否足以支撑45分钟教学片段；
4. 判断自学模式是否能作为课后任务；
5. 标注哪些资源最值得优先转为动画、互动或小游戏；
6. 判断课程能力图谱节点是否能映射到课程任务和评价。

必须记录：

1. 专业错误或不严谨之处；
2. 应删减、合并或新增的案例；
3. 教师实际讲课需要的补充材料；
4. 能否直接用于课堂，以及不能直接使用的原因；
5. 对3.5A修订的优先级建议。

## 8. 3.5A修订建议

建议在真实评审前先做一个轻量3.5A修订，避免把明显可修的问题带给一线教师和学生。

优先级P0：

1. 在首屏增加“先做什么、做完交什么、怎么判断完成”的学习入口；
2. 为每个案例增加一句明确完成标准；
3. 把最终提交物整理成一张结构化学习单或短报告；
4. 在教师页增加45分钟课堂使用建议和典型答案入口；
5. 把专业复核点集中列成清单，便于通信教师逐项审核；
6. 在右侧增加术语字典栏目，先用配置化词条解释关键术语；
7. 教师页增加模拟学情看板，明确标注为模拟数据。

优先级P1：

1. 增强自学模式中的分层提示，尤其是错误原因和再做一次路径；
2. 把课程能力图谱的学生端说明进一步教材化，减少“节点、映射、评价方式”等后台感；
3. 为五类学习活动分别补充“为什么这样练”的简短说明；
4. 对每个案例增加“能说明什么、不能说明什么”的显性边界；
5. 教师页补充课堂模式控节奏说明、自学模式布置单和验收方式。

优先级P2：

1. 选择1-2个最有效学习活动制作正式互动样例；
2. 为移动性流程排序和95分位判断设计动画脚本；
3. 为结论拼装增加错误结论修订活动；
4. 形成一份可上传出版社平台的资源清单对照表。

## 9. 当前门禁结论

样章3.5可以作为“课程能力图谱驱动数字教材”的方向验证样章，但还不是成熟的一线课堂样章。

下一步不应急于拆工具链模块。更合理的顺序是：

1. 先完成3.5A轻量修订；
2. 再做真实一线教师/学生评审；
3. 根据评审结果决定是否进入工具链拆解；
4. 若评审未通过，应继续修文本、任务和交互，而不是扩大到全书批量生产。
