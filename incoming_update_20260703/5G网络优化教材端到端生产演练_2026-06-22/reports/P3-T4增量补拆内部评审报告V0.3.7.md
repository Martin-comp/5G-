## 3. 通过点

### 3.1 没有把参数设置任务写成真实网管操作教程

本轮没有把以下对象升格为详细能力节点：

1. 每一个参数字段。
2. 每个网管软件按钮。
3. 每张参数配置截图。
4. 每一步邻区添加或删除点击操作。
5. 每个NSA锚点配置项。
6. 每个A2门限截图。
7. 每个案例截图。
8. 每个截图提交动作。

这些对象被放入资源、活动、评价、媒体审查或风险治理对象，符合“职业动作为节点，材料为支架”的拆分规则。

### 3.2 项目三链条得到实质补齐

V0.3.7中P3-T2和P3-T3已经较稳定，但P3-T4此前仍是任务骨架。本轮6个节点把P3-T4拆成一条可学习、可记录、可评价的参数设置链：

1. 先确认参数设置任务和变更依据。
2. 再识别参数对象与影响范围。
3. 然后制定邻区添加、删除或调整方案。
4. 在教学仿真或重绘界面中完成设置并记录证据。
5. 核查设置结果、风险和回退条件。
6. 形成参数变更记录并衔接复测。

这比保留“完成参数设置”一个任务节点更能支撑数字教材资源组织。

### 3.3 与P3-T3和P4-T1的边界基本清楚

本轮把P3-T4定位为“参数设置与变更证据”，避免与相邻任务混写：

1. P3-T3重点是参数检查和问题定位，不承担设置执行。
2. P3-T4重点是教学仿真下的参数设置、变更依据和证据记录。
3. P4-T1重点是优化方案实施和工程变更边界，不被P3-T4替代。
4. P4-T2、P5-T3和P6-T2承担后续验证、持续观察或复杂问题复盘。

该边界对后续整书图谱稳定性有价值。

### 3.4 风险治理没有过度乐观

本轮所有关键风险对象仍保持 `not_ready`、`pending` 或 `review_pending` 状态，没有把内部试拆误写成已专业复核、已媒体审查、可平台发布或可正式教学使用。

这是必要的。P3-T4涉及参数变更和网管截图，不能因为结构表通过就进入生产。

## 4. 主要问题

### 4.1 P3T4-N04容易被误读为真实操作训练

N04“完成教学仿真参数设置并记录证据”是本轮风险最高节点。它可以作为数字教材中的实践节点，但必须明确：

1. 只在教学仿真、教学化重绘界面或模拟数据中完成。
2. 不代表真实网管授权。
3. 不训练学生独立下发真实生产参数。
4. 操作证据不等于优化成功。

如果后续页面生产时边界写弱，本节点会带来明显教学和安全风险。

### 4.2 参数对象和案例口径需要专业复核

Massive MIMO子波束、邻区配置、NSA锚点、A2门限、QCI、SS-RSRP和SS-SINR等内容不能只凭教材原文和内部推断定稿。

后续必须确认：

1. 原教材参数解释是否仍适合当前教学。
2. NSA内容是否需要保留、转为历史场景，或替换为更适合当前5G教学的案例。
3. A2门限案例是否专业成立。
4. 邻区添加、删除和调整原则是否需要补充反例。
5. 学生端能否用低门槛语言理解参数影响，而不是只背操作步骤。

### 4.3 媒体审查仍只是挂号，不是完成

本轮把 `image180.png` 至 `image197.png` 类截图纳入媒体审查范围，但没有逐张判断。

后续至少要分成：

1. 可教学化重绘。
2. 可保留但需裁剪脱敏。
3. 只内部分析不可发布。
4. 应删除或替换。

当前成果没有完成这一步。

### 4.4 复测交接关系仍需验证

P3T4-N06把参数变更记录连接到P4-T1、P4-T2、P5-T3和P6-T2。这个设计方向合理，但具体分流规则仍需专业复核。

需要确认：

1. 哪些参数设置结果进入P4-T1实施。
2. 哪些直接进入P4-T2验证。
3. 哪些进入P5-T3持续观察和全网性能提升验证。
4. 哪些应进入P6-T2信令复盘。
5. 哪些场景应回退到P3-T3重新检查。

## 5. 是否需要调整节点颗粒度

当前不建议拆得更细。

不建议新增的节点：

1. 修改无线参数。
2. 添加邻区。
3. 删除邻区。
4. 调整邻区参数。
5. 设置NSA锚点。
6. 修改A2门限。
7. 保存截图。
8. 提交参数。
9. 导出记录。
10. 截图作为作业。

这些更像软件步骤、资源材料或评价证据，不是课程能力图谱的稳定能力节点。

可观察的问题：

1. N02未来是否需要把“参数对象识别”和“影响范围判断”拆成两个活动层，但暂不需要拆成两个节点。
2. N03未来进入学生正文时需要更强的邻区方案反例，但图谱节点无需增加。
3. N04如果后续没有教学仿真平台或可重绘界面支撑，可能需要降级为“识读操作证据”而不是“完成设置”。
4. N06未来可能需要更清晰的复测交接量规，但仍可保留为一个汇聚节点。

## 6. 对后续完整图谱的影响

P3-T4补拆说明当前图谱主数据可以承接一种高风险普通任务类型：参数设置、授权变更与回退记录类任务。

这对后续整书图谱的意义是：

1. 证明P3项目不能停留在运行监控和参数检查，还必须表达参数设置后的证据、风险和复测交接。
2. 证明V0.4风险字段可以承接工程授权、操作边界、媒体重绘、平台边界和误操作风险。
3. 证明普通任务补拆应继续采用“少量稳定节点 + 资源活动评价挂接 + 风险治理”的方式，而不是全量拆原文。
4. 证明涉及参数设置的节点即使结构通过，也必须在合并、页面和资源生产前保留更强门禁。
