# 课程能力图谱风险治理扩展表V0.4短内部复核记录

生成日期：2026-06-25  
复核对象：`reports/课程能力图谱风险治理扩展表V0.4.csv`  
前置依据：`reports/课程能力图谱风险治理扩展表V0.4校验记录.md`、`reports/课程能力图谱V0.4回填合并建议.md`  
复核结论：有条件通过。V0.4风险治理扩展表已经具备支撑下一轮任务增量验证的最低条件，但仍不能支撑页面生产、正式资源包生产或工具链模块拆解。

## 1. 复核范围

本次短内部复核只判断三件事：

1. 旁挂式V0.4风险治理扩展表是否稳定；
2. 是否可以进入下一轮任务增量验证；
3. 下一轮验证前还必须保留哪些门禁。

本复核不判断以下事项：

1. 专业内容是否已经准确；
2. 媒体资源是否已经可直接发布；
3. 学生正文是否已经达到正式教材质量；
4. 出版社平台接口是否已经可用；
5. 真实一线教师/学生试看是否已经通过。

结构层面，扩展表成立。

## 3. 复核判断

### 3.1 旁挂式扩展表方案成立

复核判断：成立。

理由：

1. V0.3.3四张主表继续保持课程能力图谱结构职责；
2. V0.4字段不直接塞入主表，避免主表膨胀；
3. 扩展表通过 `source_table`、`source_record_id`、`task_id`、`object_level` 回挂主数据对象；
4. 风险治理字段可以独立迭代，不破坏V0.3.3基线；
5. 后续任务增量可以沿用同一结构生成扩展记录。

该方案比“直接把46列并入节点表或挂接表”更稳定。

### 3.2 可以支撑下一轮任务增量验证

复核判断：有条件成立。

成立条件是：下一轮任务增量必须同步生成V0.4风险治理扩展记录，而不是只生成V0.3.x节点、关系、挂接和输入输出物记录。

建议下一轮任务增量至少产出：

1. 任务试拆报告；
2. 节点增量样表；
3. 关系增量样表；
4. 资源活动评价挂接增量样表；
5. 输入输出物治理增量记录；
6. V0.4风险治理扩展增量样表；
7. 结构校验记录；
8. 内部评审记录。

如果下一轮仍只做节点和挂接，不同步做V0.4风险扩展，当前字段治理成果会断裂。

### 3.3 不建议马上进入全书批量拆解

复核判断：不建议。

原因：

1. 当前扩展表只覆盖P1-T3、P3-T3、P4-T2三类代表任务；
2. 尚未验证更多任务类型下V0.4字段是否仍然够用；
3. `edge_master` 和 `asset_governance` 尚无实际扩展记录；
4. 阻断原因和下一步动作仍然过于通用；
5. 专业、编辑、媒体、数据安全、平台和教学验证门禁均未完成。

因此，下一步可以做“第四类任务增量验证”，但不能做“全书批量拆解”。

## 4. 关键问题

### 4.1 `gate_blocking_reason` 颗粒度不足

当前105条记录的 `gate_blocking_reason` 完全相同：

```text
仍需完成专业/编辑/数据安全/媒体/学生正文/平台/教学验证等对应门禁。
```

这个表述能防止误发布，但不能支撑精细化派单。例如，系统无法仅凭该字段区分：

1. 哪些对象是公式口径未审；
2. 哪些对象是媒体截图需重绘；
3. 哪些对象是脱敏未完成；
4. 哪些对象是客户授权未确认；
5. 哪些对象是学生正文待审；
6. 哪些对象是平台接口未接入；
7. 哪些对象是真实教学验证未完成。

建议下一轮增量验证时，将 `gate_blocking_reason` 从通用文本升级为可枚举的阻断原因字段，或新增辅助字段。

建议枚举方向：

| 建议枚举值 | 含义 |
| --- | --- |
| `professional_formula_pending` | 公式、参数、阈值或专业口径待复核 |
| `media_redraw_required` | 截图、图片或界面需重绘/替换 |
| `data_desensitization_pending` | 个人信息、地址、工单等脱敏未完成 |
| `authorization_pending` | 客户授权、录音授权或材料授权未确认 |
| `service_wording_pending` | 服务承诺、反馈话术或责任表达待审 |
| `student_text_review_pending` | 学生正文待教材化审读 |
| `platform_integration_not_started` | 出版社平台接口或挂接未开始 |
| `teaching_validation_pending` | 一线教师/学生真实使用验证未完成 |
| `publication_boundary_pending` | 发布范围、外部话术或法律边界待确认 |

### 4.2 `gate_next_action` 不能直接驱动工作流

当前105条记录的 `gate_next_action` 完全相同：

```text
按任务风险提交对应复核，并在回填样表通过后再判断是否进入合并建议。
```

该描述已经落后于当前阶段，因为回填样表、内部评审、合并建议和扩展表校验均已完成。下一轮增量验证时，`gate_next_action` 应改为能直接驱动后续处理的动作。

建议动作类型：

| 建议动作 | 适用对象 |
| --- | --- |
| `submit_professional_review` | 专业口径、公式、阈值、结论 |
| `submit_editorial_review` | 学生正文、服务表达、教材语言 |
| `submit_data_security_review` | 个人信息、录音、工单、地址 |
| `redraw_or_replace_media` | 软件截图、网管界面、非通用仿真界面 |
| `prepare_platform_mapping` | 出版社平台挂接、资源封装、接口字段 |
| `prepare_teaching_trial` | 教师带教、学生自学、课堂验证 |
| `hold_from_publication` | 不允许进入发布或对外复用 |

### 4.3 `edge_master` 暂不补造，但需要规则

当前扩展表没有 `edge_master` 记录。复核判断：当前不需要补造，但下一轮必须明确生成规则。

建议规则：

1. 关系只作为后台图谱结构使用时，不生成V0.4扩展记录；
2. 关系解释会展示给学生或教师时，应生成 `edge_master` 扩展记录；
3. 关系用于平台跳转、评价路径或学习推荐时，应生成 `edge_master` 扩展记录；
4. 关系涉及“问题回流”“责任升级”“服务承诺”“未闭环判断”等高风险表达时，应生成 `edge_master` 扩展记录。

这样可以避免为了形式完整而给所有关系都加治理记录，也能防止学生端可见关系解释脱离审查。

### 4.4 `asset_governance` 暂不补造，但需要补录边界

当前扩展表没有 `asset_governance` 记录。复核判断：当前可以接受，但下一轮必须明确补录边界。

建议规则：

1. 资产只是过程报告、校验记录或内部治理文件时，不必生成V0.4扩展记录；
2. 资产包含可进入教材正文、学生端资源、媒体库、平台上传包或对外交付材料时，应生成 `asset_governance` 扩展记录；
3. 资产包含真实数据、截图、录音、客户信息、企业软件界面或第三方来源时，应生成 `asset_governance` 扩展记录；
4. 资产是AI生成或改写内容时，应记录 `source_transformation_type` 和 `publishability_status`。

## 5. 是否可以进入第四类任务增量验证

复核判断：可以进入“第四类任务增量验证的候选选择和实施计划”，但不建议直接开始拆。

理由：

1. V0.3.3主数据结构已经稳定；
2. V0.4风险治理扩展表已经通过结构校验；
3. 三类代表风险已被字段化；
4. 继续做一个任务增量有助于验证扩展表是否能迁移到新的任务类型；
5. 但下一轮任务必须先做候选选择，避免为了扩数据而扩数据。

建议下一步先形成：

`reports/第四类普通任务增量验证候选矩阵V0.4.csv`

候选选择应优先考虑尚未充分验证的任务类型，而不是选择与P4-T2、P3-T3、P1-T3高度相似的任务。

候选任务应重点检验至少一种新风险：

1. 工程实施/现场操作类风险；
2. 工具操作与设备连接类风险；
3. 跨系统协同和责任交接类风险；
4. 学生实训安全类风险；
5. 评价数据采集和学习记录类风险；
6. 平台资源封装和学习路径跳转类风险。

## 7. 内部评分

本次短内部复核评分：86/100。

扣分原因：

1. `gate_blocking_reason` 仍是统一文本，不能支持精细化门禁；
2. `gate_next_action` 仍是统一文本，不能直接驱动工作流；
3. `edge_master` 和 `asset_governance` 尚未经过实际记录验证；
4. V0.4扩展表仅覆盖三项任务，尚未经过第四类任务迁移验证；
5. 当前只证明风险可被标出，尚未证明风险可被闭环处理。

加分依据：

1. 旁挂式扩展表结构正确；
2. 105条记录全部可回挂V0.3.3主数据；
3. 严格枚举校验通过；
4. 发布、教学验证和平台门禁保持保守；
5. 字段清单口径问题被及时发现并补正；
6. 已经能阻断“未审内容进入页面或平台”的主要风险。

## 8. 复核结论

V0.4风险治理扩展表短内部复核有条件通过。

成立的结论：

1. 旁挂式风险治理扩展层方向成立；
2. 当前扩展表可以作为下一轮任务增量验证的数据治理基础；
3. V0.4风险治理不应直接并入V0.3.3四张主表；
4. 下一步可以进入第四类普通任务增量验证的候选选择；
5. 下一轮增量必须同步生成V0.4风险治理扩展记录。

不成立的结论：

1. 不能进入页面生产；
2. 不能进入正式资源包生产；
3. 不能进入工具链模块拆解；
4. 不能宣称课程能力图谱已通过专业专家审核；
5. 不能宣称当前内容已通过真实一线教师/学生试看；
6. 不能宣称V0.4已经支撑全书规模化生产。
