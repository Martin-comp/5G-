# P5项目内部链条V0.4补齐计划

生成日期：2026-06-26  
计划对象：项目五内部链条 `P5-T1 -> P5-T2 -> P5-T3`  
前置依据：`reports/项目五内部链条评审报告V0.3.11.md`  
当前结论：先补齐P5-T3风险治理与项目五关系校正，再判断是否进入第十一类普通任务候选选择。

## 1. 本计划解决什么问题

项目五内部链条评审已经判断 `P5-T1 指标采集` -> `P5-T2 性能提升实施` -> `P5-T3 性能提升验证` 有条件成立。

但当前仍有四个结构性缺口：

1. P5-T1和P5-T2已经形成V0.4风险治理记录，P5-T3仍主要停留在V0.2/V2风险表达，项目内治理口径不一致；
2. V0.3.11同时保留了P5-T1到P5-T2、P5-T2到P5-T3的旧任务级关系和新增详细节点级关系，后续可视化、检索和学习路径推荐可能出现重复路径；
3. P5-T3到P6复杂复盘、P6回流P5的关系需要从项目五视角重新确认边界；
4. P5项目涉及大量指标表、仿真软件截图、教学案例和参数/工程边界，媒体、案例和学生正文门禁需要统一治理。

因此，本计划不继续选择第十一类普通任务，而是先把项目五内部链条补稳。

## 2. 补齐边界

本计划只做治理补齐和关系校正，不做以下事项：

1. 不重拆P5-T1八个详细能力节点；
2. 不重拆P5-T2九个详细能力节点；
3. 不重拆P5-T3七个详细能力节点；
4. 不直接改写V0.3.11四张主数据表；
5. 不生成P5学生端教材正文；
6. 不制作P5可运行页面；
7. 不制作正式图表、动画、互动或小游戏；
8. 不生成正式资源包；
9. 不接入出版社平台、学习记录库或AI助手；
10. 不选择第十一类普通任务；
11. 不把V0.4补齐等同于专业复核、媒体审查、学生正文审查、平台验证或真实教学验证完成。

本计划要回答的是：P5-T3需要补哪些V0.4风险记录，P5-T1/P5-T2/P5-T3之间的关系需要怎样校正，P5与P6的回流关系如何标注，补齐后用什么门禁判断是否可以继续选择下一类普通任务。

## 3. 项目五关系表达原则

项目五不应被写成简单的：

```text
P5-T1 -> P5-T2 -> P5-T3
```

更准确的表达应是：

```text
P5-T1 先形成可复用的指标采集包、口径和数据质量判断
-> P5-T2 根据采集包定位短板、制定方案、明确授权边界并形成实施记录
-> P5-T3 使用实施记录和复测数据验证效果，判断是否闭环
-> 未闭环或复杂问题进入P6复盘，再回到P5做建议适用边界和KPI基线复测
```

后续关系校正应区分五类关系：

| 关系类型 | 含义 | 项目五示例 |
| --- | --- | --- |
| 概括主链 | 用于项目总览，不作为学生细路径 | `P5-T2 -> P5T3-N01` |
| 输入交接 | P5-T1产出进入P5-T2任务入口 | `P5T1-N08 -> P5T2-N01` |
| 方案支撑 | 分类指标支撑P5-T2分支方案 | `P5T1-N03 -> P5T2-N03` |
| 验证支撑 | P5-T2实施记录支撑P5-T3验证 | `P5T2-N09 -> P5T3-N03` |
| 问题回流 | 未闭环问题进入P6或回到P5复测 | `P5T3-N06 -> P6T2-N01`、`P6T2-N06 -> P5T3-N03` |

旧任务级关系可以保留为项目级概括关系，但必须标注为“已由详细节点关系细化”或“仅用于项目总览”，不能和详细节点关系混成同等学习路径。

### 7.2 门禁状态规则

当前阶段不允许出现以下误标：

1. `overall_publish_gate_status=approved`
2. `professional_gate_status=passed`
3. `media_gate_status=passed`
4. `student_text_gate_status=passed`
5. `platform_gate_status=passed`
6. `teaching_validation_gate_status=passed`

除非有真实专业复核、媒体审查、学生正文审读、平台接口验证或一线教学验证证据，否则一律保持 `pending`、`revision_required`、`review_pending`、`not_started` 或 `internal_review`。

### 7.3 典型字段规则

| 场景 | 字段填写规则 |
| --- | --- |
| 涉及KPI口径、统计周期或基线 | `professional_risk_type` 包含 `metric_context` 或 `baseline_definition`，`professional_gate_status=pending` |
| 涉及验证数据源或复测路径 | `data_security_review_scope` 必须明确，必要时标注脱敏要求 |
| 涉及仿真软件截图或KPI界面 | `resource_review_object_type=screenshot`，`source_transformation_type=redrawn`，`media_gate_status=revision_required` |
| 涉及未闭环判断或P6入口 | `professional_risk_type` 包含 `handoff_boundary`，并说明二次分析边界 |
| 涉及验证报告 | `editorial_gate_status=pending`，`student_text_gate_status=review_pending`，`external_statement_allowed=no` |
