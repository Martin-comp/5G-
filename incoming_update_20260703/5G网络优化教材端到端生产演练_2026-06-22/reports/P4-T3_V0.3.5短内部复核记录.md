## 3. 关键判断

### 3.1 节点颗粒度

当前6个节点可以保留：

1. `P4T3-N01` 明确报告对象与交付口径。
2. `P4T3-N02` 归集实施与验证证据。
3. `P4T3-N03` 选择报告结构并组织材料。
4. `P4T3-N04` 对比指标并写出结论边界。
5. `P4T3-N05` 编写典型案例分析段落。
6. `P4T3-N06` 修订报告表达并准备客户沟通。

这6个节点是职业动作，不是报告章节标题，也不是教材小标题。当前没有必要在图谱主数据层继续拆细。

需要保留观察的问题是：后续教材页面生产时，`N02` 的证据归集可能需要拆成多个学习段落，但不应在图谱主数据层提前拆成多个能力节点。

### 3.2 关系链条

30条关系具备进入合并准备的结构条件，理由是：

1. P4-T3内部从交付口径、证据归集、结构组织、指标结论、案例分析到表达修订形成递进链。
2. 能承接P4-T1实施记录与变更凭据。
3. 能承接P4-T2验证依据、改善/达标边界和职业表达修订。
4. 能远端引用P2-T3测试数据分析报告，但没有让P2-T3替代P4-T2验证结论。
5. 已设置证据不足和结论边界混乱时回流P4-T2的路径。

需在V0.3.6合并准备中重点检查的问题是：跨任务支撑关系均为 `待专业复核`，合并时不得改写为已复核状态。

### 3.3 资源活动评价挂接

19条挂接可以支撑主数据层合并准备。它们覆盖任务卡、证据链清单、结构草稿、指标结论段、典型案例分析段、媒体审查对象、职业表达量规和客户沟通提纲。

但这些挂接大多处于设计和待审状态，不代表资源已经可以进入正式教材。尤其是：

1. `P4T3-IMG01` 只能作为媒体审查和重绘来源。
2. `P4T3-W04` 指标结论段必须保留专业复核。
3. `P4T3-W06` 报告样稿与沟通提纲必须标注教学模拟边界。

### 3.4 风险治理

12条V0.4风险治理增量记录能够覆盖P4-T3的主要特殊风险，包括客户沟通、外部发布、数据安全、指标结论、报告模板、站点案例和测试截图。

短复核认为这些风险记录可以旁挂进入V0.3.6合并准备，但不建议直接并入四张V0.3主表。合并准备方案应继续沿用此前做法：

1. 四张V0.3主表只处理节点、关系、资源活动评价挂接、输入输出物治理。
2. V0.4风险治理扩展表继续作为旁挂门禁层。
3. `overall_publish_gate_status`、`media_gate_status`、`professional_gate_status` 等待审字段不得被简化或删除。

## 4. 阻断项判断

| 问题 | 是否阻断V0.3.6合并准备 | 是否阻断页面/资源/平台 |
| --- | --- | --- |
| 通信专业复核未完成 | 不阻断合并准备，但必须保留待复核状态 | 阻断正式页面和资源生产 |
| 媒体截图未脱敏重绘 | 不阻断合并准备，但必须旁挂风险门禁 | 阻断正式媒体资源入库 |
| 学生端正文尚未生成 | 不阻断合并准备 | 阻断教材页面生产 |
| 客户沟通边界未外部审核 | 不阻断合并准备，但必须保持教学模拟状态 | 阻断对外发布和真实客户话术 |
| 指标阈值和结论边界待复核 | 不阻断合并准备，但不得标成已复核 | 阻断正式教学结论发布 |
| 资源仍为规划型挂接 | 不阻断主数据候选合并 | 阻断正式资源包生产 |

短复核结论：上述问题是后续生产门禁，不是当前合并准备门禁。只要V0.3.6合并准备方案明确“候选合并不等于发布可用”，即可继续。
