# 样章3.5人工反馈处理与3.5A修订需求清单

生成日期：2026-06-23  
对应文件：`reports/样章3.5一线教师学生视角评审记录.md`  
对应样章：`samples/task_workbench_3_5_graph_driven_sample/`  
性质：人工反馈处理记录 + 3.5A修订需求，不代表真实一线评审结论

## 1. 处理结论

本轮人工反馈确认：样章3.5的主要方向不需要推翻，3.5A应做定向增强，而不是重新设计。

3.5A修订重点调整为：

1. 强化学生首次进入后的学习入口和完成标准；
2. 增强互动反馈后的二次修正路径；
3. 将课程能力图谱进一步转译为学生可理解的学习导航；
4. 增加右侧术语字典栏目，后续可升级为AI助手；
5. 将教师页从提示页升级为课堂组织工具；
6. 增加模拟学情栏目，包括错误分布、常见误区和讲评优先级；
7. 保留五个案例结构，本单元不因案例数量做删减；后续单元按内容需要规划3-5个案例。

## 4. 3.5A功能需求清单

### 4.1 学生首屏学习入口

必须增加一个明确入口区，回答三个问题：

1. 我先做什么；
2. 我做完要交什么；
3. 我怎么知道自己完成得可以。

建议文案结构：

```text
先做第1例：把4条投诉线索归类。
做完要得到：一份“本次验收要看哪些数据”的初步判断。
完成标准：能说明每条投诉为什么对应覆盖、移动性、体验或容量中的一种。
```

### 4.2 每例完成标准

每个案例必须有一句完成标准。

| 案例 | 完成标准 |
| --- | --- |
| 入门样例 | 能把投诉线索对应到需要验证的数据类型 |
| 对照样例A | 能排出移动性验证流程，并说明为什么不能只看静止覆盖 |
| 对照样例B | 能区分平均值达标和尾部体验未闭环 |
| 半扶手练习 | 能把材料分成通过依据、边界和背景 |
| 独立实践 | 能写出包含判断、依据、边界、建议的验收结论 |

### 4.3 二次修正路径

每个互动反馈后应提供至少一个修正动作：

1. 再试一次；
2. 查看错误原因；
3. 看一条示范解释；
4. 修改我的判断；
5. 形成更好的结论。

反馈不能只告诉学生对错，还要说明下一步如何改。

### 4.4 课程能力图谱学生化表达

学生端不应主要看到“节点、资源映射、评价方式”等后台语言。

建议转译为：

| 后台表达 | 学生端表达 |
| --- | --- |
| P4T2-N03 读覆盖指标 | 我正在练：看覆盖是否真的达标 |
| 关联卡片 | 你可以用这些材料帮你判断 |
| 前置关系 | 学这一步之前，你需要先判断问题属于哪类 |
| 后续关系 | 学完这一步，下一步要看移动性或体验是否闭环 |
| 评价方式 | 做到什么程度算掌握 |

### 4.5 右侧术语字典

3.5A建议在右侧增加术语字典栏目，先采用配置化词条，不接入真实AI。

初始词条建议至少包括：

1. SS-RSRP；
2. SS-SINR；
3. 95分位时延；
4. PRB利用率；
5. 切换成功率；
6. RRC连接成功率；
7. 弱覆盖采样点；
8. 尾部体验；
9. 通过依据；
10. 边界。

每个词条应包含：

1. 一句话解释；
2. 本课怎么看；
3. 常见误解；
4. 和当前案例的关系。

后续升级方向：术语字典可升级为AI助手，但正式进入平台前必须处理内容安全、专业审核和回答边界。

### 4.6 教师课堂组织工具

教师页应从提示型内容升级为可直接用于课堂的组织工具。

必须增加：

1. 45分钟课时安排；
2. 投屏/板书建议；
3. 关键提问脚本；
4. 每例典型答案；
5. 常见错误及讲评话术；
6. 课堂模式控节奏说明；
7. 自学模式布置单和验收方式。

### 4.7 模拟学情看板

3.5A可以加入模拟学情，但必须标注为模拟数据。

建议栏目：

1. 各案例完成率；
2. 错误分布；
3. 高频误区；
4. 讲评优先级；
5. 建议回看能力点；
6. 典型错误答案。

模拟数据用途是验证教师页信息架构，不能伪装成真实学习数据。

### 4.8 专业复核辅助方案

非通信专业教师不应被要求自行判断专业阈值是否正确。3.5A应提供辅助而不是替代专业复核。

建议增加：

1. 专业复核清单；
2. 指标和阈值来源边界；
3. 待审核标记；
4. “本课目标，不代表行业通用标准”的持续提示；
5. 通信专业教师复核入口或导出清单。

## 5. 不纳入3.5A的事项

以下事项暂不作为3.5A必要范围：

1. 全书课程能力图谱批量抽取；
2. 真实AI助手；
3. 真实出版社平台接口；
4. 真实学生学习数据采集；
5. 正式动画、小游戏和视频批量制作；
6. 完整通信专业知识库。

这些事项应等待3.5A和真实一线试看结果后再决定是否进入。
