## 3. 复核判断

### 3.1 节点颗粒度

结论：通过。

V0.3.1A继续保留6个详细能力节点，没有因为内部评审意见重新大拆。这是合理的。P3-T3原教材包含大量公式、参数表和网管截图，如果继续细拆为公式节点、参数项节点或截图节点，会重新把课程能力图谱做成操作清单。

当前6个节点能覆盖“场景识别 -> 参数口径 -> 无线/传输/核心网检查 -> 异常清单与建议”的完整任务链，适合作为图谱主数据层的能力节点。

### 3.2 关系逻辑

结论：通过。

V0.3.1A已经把原来的线性链条：

```text
P3T3-N02 -> P3T3-N03 -> P3T3-N04 -> P3T3-N05 -> P3T3-N06
```

修订为：

```text
P3T3-N02 -> P3T3-N03
P3T3-N02 -> P3T3-N04
P3T3-N02 -> P3T3-N05
P3T3-N03 -> P3T3-N06
P3T3-N04 -> P3T3-N06
P3T3-N05 -> P3T3-N06
```

该修订解决了核心问题：无线侧、传输侧、核心网侧检查不再被误写为固定顺序，而是按问题场景选择检查分支，再汇聚到参数异常清单。

### 3.3 资源活动评价挂接

结论：通过结构门禁。

V0.3.1A将挂接记录调整为22条，主要补强点有效：

1. N02拆出容量参数读法卡、覆盖与链路预算参数读法卡、功率与接入参数边界表；
2. N03明确 `IMG-173-176` 为无线网管参数检查截图组；
3. N04明确 `IMG-155-165` 为传输组网与网管截图组；
4. N05明确 `IMG-172-177` 为核心网参数检查入口与查询截图组；
5. N06新增 `IMG-178-179` A3事件未触发切换案例截图组。

这解决了V0.3.1内部评审指出的关键遗漏。需要注意的是，当前媒体挂接仍是分组级治理，不是逐图精审。合并V0.3.2可以接受分组挂接，但后续进入正式资源制作前必须进一步拆分到单图审查。

### 3.4 专业风险状态

结论：通过内部治理门禁，但未通过专业定稿门禁。

V0.3.1A保留了高风险和待复核状态，没有把公式、参数边界、核心网QoS、传输承载参数或网管截图写成已审核内容。这一点符合当前治理要求。

后续仍需专业复核：

1. 容量、覆盖、功率公式及变量解释；
2. 无线参数边界和异常判断逻辑；
3. 传输承载参数与业务影响关系；
4. 核心网控制类参数、QoS参数和厂家实现差异；
5. A3事件未触发切换案例中邻区、目标小区、XN链路的因果表达。

### 3.5 合并风险

结论：可控。

V0.3.1A的风险不是结构风险，而是后续使用边界风险。若合并V0.3.2后被误当作“专业定稿图谱”或“页面生产就绪图谱”，会造成质量门禁失真。

因此，V0.3.2合并说明必须明确：

1. V0.3.2只是课程能力图谱主数据阶段性版本；
2. P3-T3新增节点、关系和挂接仍为内部试拆/待专业复核/待媒体审查状态；
3. 合并主数据不等于学生正文可发布；
4. 合并主数据不等于出版社平台可上线；
5. 合并主数据不等于进入工具链模块拆解。
