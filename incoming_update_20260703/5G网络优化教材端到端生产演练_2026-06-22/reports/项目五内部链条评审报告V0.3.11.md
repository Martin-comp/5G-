## 4. 链条成立点

### 4.1 P5-T1到P5-T2的输入链条成立

P5-T1不是孤立的指标采集任务。V0.3.11已经把P5-T1的输出连接到P5-T2：

| 输入关系 | 作用 |
| --- | --- |
| `P5T1-N08 -> P5T2-N01` | 全网性能指标采集包进入性能提升任务 |
| `P5T1-N02 -> P5T2-N02` | 指标口径和统计周期支撑8维短板分析 |
| `P5T1-N03 -> P5T2-N03` | 接入类采集结果支撑接入类提升方案 |
| `P5T1-N04 -> P5T2-N04` | 保持性指标支撑保持类提升方案 |
| `P5T1-N04 -> P5T2-N05` | 移动性指标支撑移动性提升方案 |
| `P5T1-N05 -> P5T2-N06` | 资源/可用类指标支撑资源与可用类方案 |
| `P5T1-N06 -> P5T2-N02` | 覆盖、互操作和干扰类指标支撑短板分析 |
| `P5T1-N07 -> P5T2-N07` | 数据质量判断约束实施方案可信度 |

这些关系说明P5-T2不是凭空制定优化方案，而是承接P5-T1采集包和口径治理结果。

### 4.2 P5-T2内部链条成立

P5-T2内部链条为：

```text
明确性能提升任务
-> 使用8维5步法定位短板
-> 制定接入/保持/移动性/资源与可用类分支方案
-> 形成实施方案、授权边界和回退要求
-> 在教学仿真环境执行参数调整并记录证据
-> 输出实施记录并交接P5-T3验证
```

判断：结构成立。P5-T2没有被写成真实网管操作教程，也没有退化为参数清单，而是把方案、授权、教学仿真、证据和交接放在同一职业动作链中。

## 5. 当前链条的主要不足

### 5.1 P5-T3风险治理口径落后于P5-T1/P5-T2

P5-T1和P5-T2均已形成V0.4风险治理扩展记录。P5-T3虽然已有7个详细能力节点，但仍主要沿用早期V0.2/V2关系口径，没有形成同等粒度的V0.4风险治理记录。

这会造成一个实际问题：项目五前两段的风险被显性治理，验证段的KPI对比、数据源选择、媒体重绘、验证结论和报告边界仍更多留在节点字段和备注中。

因此，项目五链条虽然成立，但还不够稳定。

### 5.2 任务级旧关系与详细节点级新关系存在重叠

V0.3.11中仍保留早期任务级关系：

1. `P5T1-N08 -> P5-T2` 任务级预留递进；
2. `P5-T2 -> P5T3-N01` 任务级直接递进。

同时，V0.3.11已经形成更细的节点级关系：

1. `P5T1-N08 -> P5T2-N01`；
2. `P5T2-N09 -> P5T3-N01`；
3. `P5T2-N09 -> P5T3-N02/N03/N07`。

这不是结构错误，但后续需要做关系校正：旧任务级关系应明确保留为“概括性项目链条”，或标记为已被详细节点关系细化，避免图谱可视化和自动推荐时出现重复路径。

### 5.3 P5-T2工程授权风险仍高

P5-T2涉及方案实施、参数调整、扩容分流、现场扫频、跨部门协同和回退边界。这些内容在图谱结构上已经显性治理，但仍不能直接进入学生端正式教材。

后续正文必须明确：

1. 教学仿真不等于真实网管授权；
2. 操作记录不等于优化成功；
3. 参数调整不等于工程闭环；
4. 验证交接不等于专业诊断已完成。

### 5.4 媒体和案例治理压力集中

项目五涉及 `image303` 至 `image324` 多个图表、指标界面和仿真软件截图。P5-T2还涉及地市、TOP小区、学校干扰器等经典案例要素。

当前可作为图谱结构来源，但不能直接作为正式教材资源。后续必须逐图判断重绘、标注、替换或删除，并对案例做教学模拟化或脱敏处理。

### 5.5 学生端教材正文仍未覆盖项目五全链条

当前只是图谱主数据阶段。P5-T1、P5-T2、P5-T3尚未形成完整学生端教材正文、教师带教材料、练习反馈和真实课堂验证。

项目五链条结构通过，不代表项目五数字教材整体样章已经可用。

评审判断：需要做项目五关系校正，但建议放入V0.4补齐计划统一处理，不单独生成临时修正表。

理由：

1. 任务级旧关系与详细节点级新关系存在重叠；
2. P5-T3缺少V0.4风险治理记录；
3. P5-T2到P5-T3的验证支撑关系需要专业教师确认；
4. P5-T3到P6复盘、P6回流P5的关系需要在项目五视角下重新检查；
5. 媒体和案例风险分散在P5-T1、P5-T2、P5-T3中，适合统一补齐。
